# 시퀀스 회로 학습 페이지 (sequence-circuit-lab)

릴레이 시퀀스 회로를 **보고(시뮬레이션) · 해석하고 · 핀번호를 적고 · 단자대 번호를 매기고 · 결선**해 보는 정적 웹 페이지 모음입니다. 전기기능사 공개과제 회로(001~018)와 승강기기능사 회로(e01~e10)를 다룹니다.

- 실제 운영 사이트: <https://seq.ksetech.org>
- 만든 사람: 박창우 (Chang-woo Park, duo0083) — [@ditduo0083](https://github.com/ditduo0083)
- 학생 정보를 서버에 저장하지 않습니다. 로그인 없이 쓰고, 결과는 기기 안에서만 다룹니다.

## 구성

| 폴더 | 내용 |
|---|---|
| `00_전기기능사_시퀀스_시각화_001-018/` | 학습 페이지(회로별 `index.html`, 해석·핀번호·결선), 통합 목차 |
| `핀번호_작업/v2_엔진분리/` | 공용 엔진(`공용/`), 회로 데이터(`회로/`), 검사 도구(`검사/`) |
| `스킬_제작/` | 위 페이지를 만들 때 쓰는 AI 에이전트용 작업 지시문 |
| `ARCHITECTURE.md` | 구조·데이터 형식·검사 방법 |

보는 법: 저장소를 내려받아 `00_전기기능사_시퀀스_시각화_001-018/00_통합목차.html`을 브라우저로 열거나, 폴더에서 `python -m http.server`를 실행해 접속하세요.
