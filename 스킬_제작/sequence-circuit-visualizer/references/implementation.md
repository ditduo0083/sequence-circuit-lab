# 예제의 구성과 수정 위치

## 원본 도면 저작권 규칙

한국산업인력공단 공개도면의 이미지·PDF·원문 문구는 만든 자료와 ZIP에 넣지 않는다. 원본은 큐넷 공개문제 자료실 링크로 안내한다. 동작 설명은 도면 원문을 옮기지 말고 회로 동작을 이해한 뒤 자기 말로 쓴다.

- 도면 PDF 11-4쪽 저작권 문구(저작권자 한국산업인력공단, 일부 또는 전부의 복제·배포·전자출판 금지)가 근거다.
- 회로도·기구 그림이 필요하면 SVG로 다시 그린다. 원본 캡처를 배경으로 깔거나 모달에 넣지 않는다.
- 검증 화면 캡처에도 원본 도면이 찍히지 않게 한다.

## 파일 역할

| 파일 | 수정할 내용 |
|---|---|
| `index.html`, `styles.css` | 회로 제목, 기기 목록, 조작 패널, 상태 표시와 배치 |
| `circuit-model.js` | 입력·코일·접점·부하·타이머 상태와 유지 조건. Node와 브라우저에서 동일한 모델 사용 |
| `circuit-diagram.js` | 실제 SVG 기호, 배선 노드, 접점 연결, 부하 연결, 확대 범위 |
| `lessons.js` (②) | 단계별 상태, 기기 설명, 자유 조작 설명 |
| `app.js` | 이벤트, 화면 갱신, 단계 복원, 자유 조작 시계. ①은 수업 설명도 이 파일에 있음 |
| `index.html`의 `reference-dialog` | 원본 도면 안내 모달. 이미지 없이 안내문과 큐넷 공개문제 자료실 링크만 둔다. 종목명(`'전기기능사'`)만 새 과정에 맞게 바꾼다. (예전 `참고자료/` 원본 PNG는 2026-09-20 스킬에서 뺐다) |
| `검증/model.test.cjs` | 각 예제에 해당하는 동작 시험. 새 도면의 기대값으로 변경 |
| `검증/browser-check.cjs` | 예제 전용 브라우저 시험. 장면 번호·선택자·동작 단언을 함께 변경 |

`assets/templates/sequential`과 `alternating`은 완성된 예제 앱이다. 원본 수업 결과의 미리보기 서버, 화면 캡처, ZIP, 한 번만 쓰는 배치 변환 스크립트는 포함하지 않는다. 실행에는 외부 라이브러리가 필요 없다. 검증에만 Node와 Playwright/Chrome을 사용한다.

## 상태 계약

두 예제는 `new Model()`, `set(key,value)`, `tick(seconds)`, `state()`, `snapshot()`, `restore(snapshot)`, `reset()`을 제공한다. 입력은 `power, mode, sensor, start, stop, trip, delay, interval`이며 `mode`는 A/M이다. `state().contacts`는 닫힘 여부, `state().loads`는 부하 여자 여부다. 새 회로에 맞게 확장할 수 있다.

②는 `x`, `timerOn`, `elapsed`, `done`, `fr`, `alternatingElapsed`를 구별한다. X 자기유지의 이전 상태를 평가할 때 전원 차단·PB0·트립 등 해제 조건을 먼저 반영한다. T 완료 시 FR 시간이 시작되어야 한다. 큰 `tick(dt)`가 지연 완료점을 넘으면 FR에는 `dt - 남은 T 시간`만 더한다.

SVG는 접점이 닫힌 그래프에서 전원 노드 도달 여부를 계산하고 이를 `diagram.calculatedLoads`로 노출한다. 부하를 단순 도선으로 연결해 전원 양측을 합치지 않는다. 모델 부하와 그래프 결과의 일치를 검사하되, 두 구현이 같은 오독을 공유할 수 있으므로 원본 비교도 한다.

## 시간과 조작

- 단계별 설명은 상태 스냅샷을 재현한다. 이전 단계로 돌아가도 잔여 타이머나 이전 FR 위상이 섞이지 않아야 한다.
- 자동 장면 넘김 시간과 실제 T/FR 시간을 구별한다. 자유 조작만 실제 시계로 진행하며, 일시정지는 모든 모델 시간을 정지한다. 재개 시 숨겨진 시간만큼 몰아서 진행하지 않는다.
- PB0/PB1은 순간 누름이다. pointer up/cancel/lost capture, 버튼 밖에서 놓기, Space/Enter 놓기 및 창 포커스 상실을 처리한다. 단계 장면의 “누른 상태”를 창 blur만으로 바꾸지 않는다. 자유 조작 상태에서만 실제 눌림을 해제한다.
- 스위치를 바꾸면 즉시 접점·부하·문구를 갱신한다. 타이머 숫자 갱신을 줄이더라도 입력 사건의 렌더링을 지연하지 않는다.

## 수업 화면

큰 회로도, 간결한 조작 패널, 현재 단계의 원인·결과를 한 화면에 배치한다. 예제의 밝은 배경과 선명한 색, 전체/제어/운전/경보 확대, 관련 기기 강조를 기본으로 재사용한다. 새 회로의 분기 구조에 맞춰 보기 이름과 범위를 바꾼다.

SVG 선 위에 열린 접점의 원본 래스터 기호를 남기고 닫힘 선만 덧그리지 않는다. 접점 자체를 벡터로 개폐한다. `text { stroke: none; }`으로 활성 그룹의 굵은 선이 글자에 상속되지 않게 한다. 확대는 viewBox뿐 아니라 일치하는 clipPath를 사용해 빈 여백에 범위 밖 부품이 노출되지 않게 한다.

1366×768 교실 화면에서 핵심 조작과 설명이 보이는지 확인한다. 작은 화면은 본문 전체를 넘치게 하지 말고 회로 영역 내부에 필요한 이동을 둔다. 기기 상태는 색에 더해 운전/정지, 여자/소자, 열림/닫힘을 표시한다.

## 예제 검증 실행

생성 폴더에서 `node --test 검증/model.test.cjs`를 실행한다. 브라우저 검증은 `node 검증/browser-check.cjs`이다. Playwright가 일반 설치되어 있으면 그대로 사용하고, 번들에 있으면 `PLAYWRIGHT_MODULE`을 실제 모듈 경로로 지정한다. Chrome 경로를 지정할 때는 `BROWSER_EXECUTABLE`을 사용한다. 지정하지 않으면 설치된 Chrome 채널을 사용한다. 다른 PC의 런타임 경로를 하드코딩하지 않는다.

스크립트가 만드는 `검증/화면/`과 `browser-results.json`은 해당 실행의 결과다. 기존 결과를 복사해 새 앱을 검증했다고 보고하지 않는다. ZIP에는 실행 파일·우리가 만든 상대경로 자료·교사용 안내를 포함하고(공단 도면 이미지·PDF는 넣지 않는다) 검증 스크립트나 `_template-origin.json`은 제외해도 된다.

## 원본에 맞춘 접점 기호

예제의 `contactSymbol`은 제어접점의 세로 막대·단자와 작동 표시를 그리고, `setContactClosed`는 모델의 닫힘 상태로 이를 이동한다. 원본이 같은 계열일 때 PB 가로선, SS 선택 표시와 기계적 점선, EOCR ×, FR ◆, T 한시 표시를 재사용할 수 있다. T 순시 접점에는 한시 표시를 붙이지 않는다. 한시 a와 한시 b의 구별은 `kind`와 실제 초기·완료 상태를 함께 대조한다. 다른 원본 기호는 새로 판독해 그린다.

FR MC1 측처럼 코일 소자 시 닫힌 b접점은 부하 OFF와 독립적으로 표시한다. 상류 경로가 끊어지면 접점이 닫혀 있어도 통전되지 않는다. SS의 점선 연결은 실제 두 접점 좌표와 선택 상태를 따른다. 주접촉기 사선과 MCCB 곡선은 별도 도형이다. 선택 강조 사각형은 기호 주위로 한정하고 인접 접점의 이름을 가리지 않게 한다. 타이머 이름에는 순시/한시를, 짧은 상태 줄에는 a/b·열림/닫힘을 표시해 인접 배선과 겹침을 줄인다.

`node 검증/contact-symbol-check.cjs`는 예제의 실제 SVG 단자·막대 좌표, 열린 접점 비통전, 작동 표시, FR 정상 상태를 검사한다. 브라우저 검사와 같은 `PLAYWRIGHT_MODULE` 및 `BROWSER_EXECUTABLE`을 사용한다. 새 회로에 맞게 장면 수·기기별 기대값을 조정하고, 주요 상태 캡처를 직접 살핀다. 기호 수정이라도 한시 b의 복귀·트립·RESET을 포함한 기존 동작 시험을 재실행한다.
