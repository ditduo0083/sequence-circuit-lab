# 수업용 회로 검증

새 회로의 원본과 주요 사건에서 기대되는 상태를 먼저 적고 구현 결과와 비교한다. 아래 항목은 회로에 존재하는 기능만 적용한다. 예제에 있던 기능을 검증 항목에 맞추려고 추가하지 않는다.

## 논리와 배선

| 사건 | 확인할 것 |
|---|---|
| 전원 OFF/ON | 모든 부하 차단, EOCR 등의 상시 전원 위치, 유지 상태 소실 |
| 자동 선택·감지·해제 | FLS 전원, 자동 기동 조건, 감지 해제 뒤 정지 범위 |
| 수동 PB1 누름/놓음 | 올바른 코일의 자기유지, 타이머와 모터의 시작 시점 |
| PB0 | 실제 설치된 분기만 차단, 계시 중 정지 후 지연 기동이 남지 않음 |
| T 설정시간 직전/일치/직후 | 순시와 한시 접점 구별, 후속 부하 시작 시점 |
| FR 첫 구간·두 번째·복귀 | 무엇이 교대하는지, 최초 위상, 동시에 켜지면 안 되는 부하 |
| EOCR 트립 | 운전 차단과 경보 공급의 분리, 경보 지속 또는 교대의 정확성 |
| RESET | 자동 감지 유지 및 수동 기동 입력에 따른 재기동 여부 |
| 모드 전환 | 새 경로 재평가, 유지 해제에 사용한 이상화 가정 |
| 시간 증가·복원 | 큰 시간 증가의 경계 처리, 스냅샷 복원, 일시정지 |

주요 장면에서 `state().loads`와 배선 그래프의 부하 결과를 대조한다. 통전 경로가 열린 접점을 건너거나 접지를 따라 흐르는지 원본·화면으로 확인한다. 정방향 단계만 확인하지 말고 입력을 바꾼 뒤 이전 상태가 잘 지워지는지 본다.

## 실제 브라우저

- `file://`로 열어 네트워크 없이 스크립트·스타일이 로드되고, 원본 안내 모달에 깨진 이미지 없이 안내문과 큐넷 링크가 나오는지 확인한다.
- 이전/다음, 장면 자동 재생, 자유 조작, 전원, 감지, 기동/정지, 트립/RESET을 조작한다.
- 버튼 밖에서 놓기, Space/Enter 누름과 놓기, 포커스 이탈 후 눌림이 남지 않는지 확인한다.
- T·FR 일시정지와 재개, 단계 복원, 입력 중인 설정값이 자동 화면 갱신으로 덮이지 않는지 확인한다.
- 접점의 실제 도형이 상태와 일치하는지 확인한다. 초기 b접점은 닫힘, 한시 a/b는 설정시간 전후와 복귀를 구별한다. 열린 접점은 막대와 단자가 떨어져 있고, 닫힌 접점은 이어져야 한다. PB·SS·EOCR·FR·T 작동 표시와 글자 겹침도 원본과 비교한다.
- 실제 주요 상태의 화면을 캡처해 기호 개폐, 흐름, 제목·설명의 일치와 글자 겹침을 직접 살핀다.
- 교실 크기 1366×768, 넓은 화면, 좁은 화면을 확인한다. 본문 가로 넘침과 확대 범위 밖의 SVG 잔상이 없어야 한다.

## 전달 직전

원본 파일은 보존하고 새 자료는 결과 폴더에 상대경로로 포함한다. 새 도면 번호와 안내 문구가 맞는지 검색한다. ZIP 내부의 모든 실행 자원이 최신 결과와 일치하고, 공단 도면 이미지·PDF가 0건인지 확인한다. 시험하지 못한 환경은 명시하고 결과 수치를 만들어내지 않는다.

`회로_동작_검증표.md`에는 입력, 기대 결과, 실제 결과, 채택한 가정을 기록한다. `교사용_사용안내.md`에는 실행 방법, 가장 이해하기 쉬운 첫 시연 순서, 기본 시간값의 의미, 단계 설명과 자유 조작의 차이를 적는다.
