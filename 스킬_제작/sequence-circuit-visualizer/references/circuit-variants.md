# 두 예제를 구별하기

이 자료는 함께 제작한 FLS 도면 ①·②의 해석이다. 전기기능사 회로 전체에 적용되는 규칙이 아니다. `assets/templates/` 안의 두 예제는 해당 도면의 작동 예시이며, 다음 회로의 정답으로 간주하지 않는다. 원본 도면은 스킬에 넣지 않는다. 확인이 필요하면 큐넷 공개문제 자료실에서 전기기능사 공개문제 ①·②를 본다. (예전 `참고자료/` 이미지는 2026-09-20에 옮겼다)

| 비교 | sequential · 도면 ① | alternating · 도면 ② |
|---|---|---|
| 자동 감지 | X 및 MC1 여자, M1·RL 즉시 동작 | X·T 여자, 초기에는 두 모터 정지 |
| 자동 모터 동작 | M1만 운전. X b접점이 T 경로 차단 | T 설정시간 후 FR 여자, M1부터 교대 |
| 수동 PB1 기동 | T·MC1 여자, M1 즉시 운전 | X·T 여자, 초기 지연 대기 |
| PB1 병렬 자기유지 | T의 순시 a접점 | X의 a접점 |
| T 한시 접점 | MC2를 추가 기동. M1은 계속 운전 | FR 및 교대 운전부에 전원 공급 |
| FR 역할 | EOCR 트립 후 BZ ↔ YL 교대 | 정상 운전 중 MC1·RL ↔ MC2·GL 교대 |
| 과부하 경보 | FR 여자, BZ부터 YL과 교대 | FR 소자, YL과 BZ 동시에 계속 동작 |
| 모터 동시 운전 | 수동 지연 완료 후 M1·M2 둘 다 ON | 어느 교대 구간에서도 둘 다 ON하지 않음 |

## 놓치기 쉬운 연결

- PB0는 두 예제 모두 수동 분기에 있다. 자동 운전에서도 항상 정지시키는 공통 정지 버튼으로 모델링하지 않는다.
- EOCR 기기 전원은 운전용 b접점보다 앞에서 공급된다. 트립으로 운전 분기가 끊겨도 경보와 EOCR 전원은 유지된다. MCCB OFF는 경보도 끈다.
- EOCR RESET은 현재 스위치와 감지 입력을 다시 평가한다. 자동 감지가 유지되면 ①은 M1이 즉시, ②는 새 초기 지연 뒤 M1이 재기동할 수 있다.
- M→A 전환 시 감지가 유지되면 자동 경로가 성립할 수 있다. 참고 설명의 “모두 정지”를 영구 정지 상태로 강제하지 않는다.
- ②에서 T의 초기 지연과 FR의 교대 주기는 다른 시간이다. 교대 때마다 T를 다시 세지 않는다.

## 예제에 사용한 학습 가정

- ①은 T 5초, FR 1초, ②는 T 5초, FR 2초가 기본 예시다. 도면의 고정 수치가 아니며 사용자 설정이나 새 자료를 따른다.
- ②의 FR은 제공 설명에 맞춰 M1부터 시작한다. 흐릿한 FR 기호만 보고 제조사별 초기 접점 상태를 단정하지 않는다.
- 모드 전환은 기존 자기유지가 해제된 뒤 새 선택 경로가 성립하는 이상적인 전환으로 취급한다. 실제 스위치의 접점 전환 시간이나 코일 소자 지연을 계산하지 않는다.
- FR 간격 변경은 새 간격의 첫 위상부터 다시 시작하는 수업용 설정 동작이다. 물리 제품의 보편적 동작으로 설명하지 않는다.
- FLS는 감지 ON/OFF 입력으로 단순화했다. 도면만으로 탱크 수위, 급·배수 방향, 전극 길이, 히스테리시스를 만들어내지 않는다. 실제 수위 장면이 필요하면 근거를 먼저 확인한다.

## 새 회로로 바꾸는 순서

1. 부하가 전원에 연결되는 경로와 각 접점 조건을 새로 작성한다.
2. 유지 접점, 타이머 종류, 정지 및 보호 분기를 식별한다.
3. 주요 입력 사건 전후의 코일·모터·램프·경보 표를 먼저 만든다.
4. 해당 표에 맞춰 모델과 SVG 접속 관계를 수정한다.
5. 수업 장면·설명·표시·시험·원본 이미지가 동일한 새 회로를 가리키게 맞춘다.
