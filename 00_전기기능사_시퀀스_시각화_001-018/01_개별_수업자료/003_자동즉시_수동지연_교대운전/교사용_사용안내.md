# FLS 도면 003 교사용 사용안내

## 실행

`index.html`을 Chrome 또는 Edge에서 직접 엽니다. 인터넷, 계정, 별도 서버가 필요하지 않습니다. 코드 파일을 `index.html` 옆에 그대로 두어야 시뮬레이션이 정상 작동합니다.

이 결과물은 접점과 코일의 이상적인 논리 동작을 보여주는 수업용 모형입니다. 실측 전류, 접촉기 응답시간, FLS 전극 높이·히스테리시스, EOCR 열동 특성은 계산하지 않습니다.

## 가장 이해하기 쉬운 첫 시연

1. `자동 운전`에서 다음 단계로 이동해 MCCB와 SS(A)를 확인합니다.
2. 수위 감지 단계에서 T·X는 소자된 채 FLS 접점이 FR에 직접 전원을 공급하고 M1·RL이 즉시 켜지는 것을 확인합니다.
3. 다음 단계에서 FR 접점이 바뀌어 M2·GL로 교대되는 것을 확인합니다.
4. `수동 운전`으로 바꾸어 PB1을 누른 뒤 놓습니다. PB1과 병렬인 T 순시 a접점이 자기유지합니다.
5. T 설정시간 경계에서 한시 a접점이 닫히고 X → FR → MC1 순으로 동작하는 것을 확인합니다.
6. `과부하 경보`에서 운전용 EOCR b접점과 경보용 a접점의 반대 동작, YL·BZ 동시 지속을 확인합니다.
7. `자유 조작`에서 실제 초 단위 계시, 일시정지, 모드 전환, RESET을 직접 시험합니다.

## 원본에서 읽은 회로 동작

- 자동: SS를 A에 두면 FLS 코일에 전원이 공급됩니다. 감지 접점이 닫히면 FR 공급 공통점이 즉시 통전되어 FR과 MC1이 여자되고 M1·RL부터 동작합니다. 자동 경로에는 T 초기 지연이 없고 X도 여자되지 않습니다.
- 수동: SS를 M에 두고 PB1을 누르면 T가 여자됩니다. PB1과 병렬인 T 순시 a접점이 T를 자기유지합니다. T 한시 a접점이 설정시간 뒤 닫히면 X가 여자되고, X a접점이 FR 공급 공통점을 연결해 M1부터 교대 운전을 시작합니다.
- 교대: FR의 첫 위상은 MC1·M1·RL, 다음 위상은 MC2·M2·GL입니다. 정상 상태에서 두 모터는 동시에 운전하지 않습니다.
- 정지: 자동에서는 FLS 감지 해제 또는 SS의 M 전환으로 정지합니다. PB0는 수동 분기에 있으므로 자동 운전에는 영향을 주지 않습니다. 수동에서는 PB0 또는 SS의 A 전환으로 T 자기유지가 해제되어 전체 운전이 정지합니다.
- 과부하: EOCR 트립 시 운전용 b접점이 열리고 경보용 a접점이 닫혀 YL과 BZ가 동시에 계속 동작합니다.

## 도면과 동작사항을 함께 읽을 때의 주의

실제 7페이지(인쇄 11-7)와 실제 8페이지(인쇄 11-8)의 핵심 동작은 서로 일치합니다. 다만 동작사항은 모드 전환 순간에 PB1이 눌려 있는 경우와 RESET 시 남아 있는 입력의 처리까지는 상세히 적지 않습니다. 시뮬레이터는 도면 배선을 따라 전원을 다시 계산합니다.

- A → M: 기존 자동 경로를 끊고 수동 입력을 평가합니다. PB1이 눌려 있으면 T가 처음부터 계시하고, 눌려 있지 않으면 기동 대기합니다.
- M → A: T 자기유지와 X가 해제됩니다. FLS 감지가 유지 중이면 FR과 M1이 즉시 동작하고, 감지가 해제되어 있으면 정지합니다.
- EOCR RESET: 트립 중 유지 상태는 소실된 것으로 봅니다. 수동은 PB1이 현재 눌려 있을 때만 T 계시를 다시 시작합니다. 자동은 감지가 유지 중이면 T 지연 없이 M1부터 즉시 재기동합니다.
- MCCB OFF → ON도 같은 방식으로 현재 모드와 입력을 다시 평가합니다.

모드 전환은 이전 선택 경로가 끊어진 뒤 새 경로가 성립하는 이상적인 전환으로 표현했습니다. 실제 SS 접점의 전환시간과 릴레이 소자 지연은 재현하지 않습니다.

## 시간과 FR 위상 가정

- T 기본값 5초와 FR 간격 기본값 2초는 도면에 고정된 수치가 아니라 수업 시연용 설정입니다.
- T는 수동 기동에서만 계시합니다. 자동 감지는 T를 사용하지 않습니다.
- FR은 여자되는 즉시 M1 위상으로 시작합니다. 설정 간격이 지나면 M2, 다시 같은 간격이 지나면 M1로 돌아옵니다.
- 운전 중 FR 간격을 바꾸면 학습 편의를 위해 M1 위상, 경과 0초부터 새 간격을 적용합니다.
- 감지 해제, PB0 정지, 모드 전환, 전원 차단, EOCR 트립 후 재기동 시 FR은 M1 위상부터 새로 시작합니다.

## 화면 사용

- `전체 / 제어회로 / 운전부 / 경보부`로 확대 범위를 바꿀 수 있습니다.
- `같은 기기 찾기`에서 X, T, MC1, MC2, EOCR, FR, FLS를 누르면 관련 코일과 접점을 함께 강조합니다.
- 청록색 굵은 선은 부하까지 닫힌 통전 경로, 파란색 얇은 선은 전원 측까지 연결되었으나 부하를 통과하지 않는 구간, 회색은 비통전 구간입니다. 색은 교류 전류의 실제 방향을 뜻하지 않습니다.
- 단계별 설명은 저장된 학습 장면으로 이동합니다. 자유 조작은 실제 시간으로 진행되며 `시간 일시정지`를 누르면 T와 FR 시간이 모두 멈춥니다.
- PB1과 PB0는 누르고 있는 동안만 입력되는 순간동작 버튼입니다. 마우스, 터치, Space, Enter로 조작할 수 있습니다.
- BZ 소리는 기본 OFF이며 사용자가 `소리 ON`을 선택한 뒤에만 납니다.

## 접점 기호 개선 (2026-09-15)

제공 도면의 세로 접점 막대와 작동 표시를 반영했습니다. PB의 가로 작동선, SS의 선택 표시와 점선 연결, EOCR의 × 표시, FR의 ◆ 표시, T 한시 표시를 구분합니다. MC 주접점의 사선과 MCCB의 곡선도 각각 표현합니다.

T 순시 a접점은 자기유지에, T 한시 a접점은 지연 후 X 기동에 쓰입니다. 접점 옆에는 a/b와 현재 열림·닫힘을 표시합니다. FR의 MC1 측 b접점은 소자 상태에서도 닫혀 있으며, 전원 경로가 이어져야 모터가 운전합니다.

열린 제어접점 막대는 단자 오른쪽으로 떨어지고, 닫힌 막대는 왼쪽에서 두 단자와 연결됩니다. 개폐 간격과 MCCB 개방 틈은 수업에서 구별하기 위한 표현이며 실제 기구의 이동 거리·속도를 재현하지 않습니다. **운전부 → 다음 단계**로 접점을 확대해 확인하세요.
