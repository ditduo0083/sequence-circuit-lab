## 모델과 SVG 배선 대조

브라우저에서 각 단계 장면과 고정 시드 혼합 입력을 렌더링한 뒤 `state().loads`의 EOCR, YL, BZ, FLS, T, X, FR, MC1, MC2, RL, GL 상태를 SVG 접점 그래프의 `calculatedLoads`와 각각 비교했습니다. 624개 상태, 6,864개 부하 비교에서 불일치는 0개였습니다.

통전 표시는 닫힌 접점 그래프에서 전원 상단과 부하 양단이 연결된 경우에만 켜지도록 확인했습니다. 열린 FLS·PB1·T·X·FR 접점을 건너는 통전이나 PE를 귀로로 사용하는 표시는 없었습니다.

## 실제 브라우저 조작

- 자동 FLS 감지 즉시 M1 기동과 T·X 미사용
- M1→M2 교대, 이전 단계 복원
- 수동 T 자기유지, T 완료 뒤 X·FR·M1 기동
- 자유 조작의 실제 T·FR 시간과 일시정지·재개
- Space·Enter 누름/놓음, 버튼 밖에서 포인터 놓기, 포커스 이탈 해제
- 과부하 YL·BZ 지속, 수동·자동 RESET 차이
- 시간 설정 입력 중 화면 갱신으로 값이 덮이지 않는지 확인
- 원본 자료 대화상자의 두 PNG 로드

캡처는 `검증/화면`에 8장, 수치 결과는 `검증/browser-results.json`에 보관했습니다.

## 채택한 가정과 남은 실물 확인 항목

- 도면과 동작사항에 고정 시간값이 없으므로 T 5초, FR 2초를 수업 기본값으로 사용했습니다.
- FR 최초 출력은 동작사항의 “MC1이 여자” 문구에 따라 M1 위상으로 두었습니다.
- 모드 전환, MCCB 재투입, RESET은 이전 자기유지를 지운 뒤 현재 입력을 즉시 다시 평가하는 이상적인 동작입니다.
- FR 간격 변경은 물리 부품의 보편 동작이 아니라 수업용으로 M1부터 재시작합니다.
- 실제 FR 제품의 최초 출력 단자, 접점 전환 공백, 릴레이 복귀시간, FLS 감지 특성, EOCR 리셋 방식은 실물과 별도 대조해야 합니다.
