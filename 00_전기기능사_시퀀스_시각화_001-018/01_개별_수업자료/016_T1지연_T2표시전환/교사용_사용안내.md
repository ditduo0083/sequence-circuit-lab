# 전기기능사 도면 016 수업용 시각화 사용안내

## 실행과 추천 시연 순서

1. `index.html`을 Chrome 또는 Edge에서 엽니다. 인터넷 연결과 계정은 필요하지 않습니다.
2. **PB1 · T1 지연** 탭에서 PB1 즉시 기동과 LS1→T1 설정시간 후 자동 기동을 비교합니다.
3. T1 완료로 M1이 기동한 뒤 LS1을 해제해도 X1 자기유지로 M1 운전이 계속되는 것을 확인합니다.
4. **PB2 · LS1 허가** 탭에서 LS1이 없을 때 PB2가 동작하지 않고, LS1 감지 중에는 X2 자기유지가 성립하는 것을 확인합니다.
5. **T2 · M2/WL 전환** 탭에서 LS2 감지 직후 M2·GL 운전, T2 완료 후 M2·GL 소등과 WL 점등, LS2 해제 후 M2 재운전을 시연합니다.
6. PB0 공통 정지와 EOCR 과부하→YL→RESET을 확인한 뒤 `자유 조작으로 전환`에서 학생이 재현하게 합니다.

T1 3초·T2 5초는 수업 시연 기본값이며 원본 도면에 고정된 설정값이 아닙니다.

## 화면 읽기와 조작

- 청록색 굵은 선은 부하까지 완성된 통전 경로, 파란색은 전원 측 연결, 회색은 비통전 경로입니다.
- 접점은 색뿐 아니라 막대 위치와 `a/b`, `순시/한시`, `열림/닫힘` 문구로 구분합니다.
- T1 또는 T2 버튼을 누르면 코일과 모든 관련 접점을 함께 강조합니다.
- PB0·PB1·PB2는 순간 누름, LS1·LS2는 감지 상태 토글입니다.
- 단계별 설명은 저장한 상태를 복원합니다. 자유 조작은 실제 시간으로 계시하며 시간 일시정지·재개가 가능합니다.
- 전체/제어회로/운전부/경보부 확대와 원본 7·8쪽 보기를 지원합니다.

## 핵심 판독

- LS1 a→T1 코일. T1 한시 a는 M1 자동 기동, T1 순시 a는 M2 분기 공통 허가입니다.
- M1: `PB1 a ∥ X1 a ∥ T1 한시 a` → MC1·X1 병렬 여자 → M1·RL 운전.
- LS2 a→T2 코일. T2 순시 a는 PB2·X2 a와 병렬로 X2를 기동합니다.
- M2: `(PB2 a ∥ X2 a ∥ T2 순시 a) AND T1 순시 a` 뒤에서 T2 한시 b→MC2·M2·GL, T2 한시 a→WL로 나뉩니다.
- T2 완료 시 M2에서 WL로 전환되고, LS2 해제 시 T2가 복귀해 M2가 다시 운전합니다.
- EOCR 운전 b는 PB0 앞 운전 버스를 차단하며 경보 a는 PB0와 별도로 YL을 켭니다.
