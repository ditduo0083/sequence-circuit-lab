## 회로 연결

EOCR 운전 b → 공통 PB0 b 뒤에서 1번 (PB1 a ∥ T1 한시 a), 2번 (PB2 a ∥ T2 한시 a)로 나뉩니다. 1번 합류 뒤에는 X1, LS1 a → MC1, X2 b → T1이 병렬이며 2번은 X2, LS2 a → MC2, X1 b → T2가 병렬입니다. WL은 (X1 a → MC1 b)와 (X2 a → MC2 b)의 병렬 경로로 공급합니다. MC 보조 a는 RL·GL을 공급합니다. EOCR 경보 a → YL은 운전 b와 PB0보다 앞에서 분기합니다.

| 접점 | 구동·입력 | 정상 상태 | 연결 위치 | 역할 |
|---|---|---|---|---|
| EOCR 운전 b / 경보 a | EOCR | 정상 닫힘 / 열림 | 운전 공통선 / YL | 트립 시 운전 차단·YL 점등 |
| PB0 b | 정지 누름 | 미누름 닫힘 | 두 운전 계통 공통선 | 두 계통 유지·모터·T 전체 정지 |
| PB1 a ∥ T1 한시 a | PB1 / T1 | 열림 / 미완료 열림 | 공통선 → 1번 합류 | T1 완료 후 자기유지 |
| PB2 a ∥ T2 한시 a | PB2 / T2 | 열림 / 미완료 열림 | 공통선 → 2번 합류 | T2 완료 후 자기유지 |
| X2 b / X1 b | X2 / X1 | 소자 시 닫힘 | 1번 합류 → T1 / 2번 합류 → T2 | 상대 계통의 타이머 차단 |
| LS1 a / LS2 a | 리밋 감지 | 미감지 열림 | 각 합류 → MC1 / MC2 | 감지 시 즉시 모터 기동 |
| X1 a → MC1 b | X1 / MC1 | 열림 → 닫힘 | 공통선 → WL | 1번 선택·모터 대기 |
| X2 a → MC2 b | X2 / MC2 | 열림 → 닫힘 | 공통선 → WL | 2번 선택·모터 대기 |
| MC1 a / MC2 a | MC1 / MC2 | 소자 시 열림 | 공통선 → RL / GL | 모터 운전 표시 |

## 판독과 표현

설명문에 제시된 타이머 완료 후 LS 감지 시연은 한 가지 조작 순서입니다. 회로에는 LS와 MC 사이에 지연 접점이 없으므로 LS가 먼저 감지된 경우의 즉시 기동도 구현했습니다. 전환 설명은 이전 PB를 놓은 조건으로 읽습니다.

접점·배선 간격은 화면에 맞게 조정하고 직렬·병렬, 분기·합류 관계를 유지했습니다. 접점은 벡터 가동부 자체를 움직여 개폐합니다. LS 사각형 가동부, PB 작동선, EOCR 교차 표시, T 한시 표시를 구분하며 b접점은 코일 소자 시 닫힙니다. 소자 상태와 열린 상태를 동일하게 취급하지 않습니다.

- 자기유지 접점은 T1·T2의 한시 a입니다. 설정시간 전 버튼을 놓으면 X와 T가 복귀하고 누적 시간도 0초가 됩니다.
- LS1·LS2는 각 MC에 직접 직렬 연결된 a접점입니다. 감지되면 타이머 완료 여부와 무관하게 현재 공급되는 계통의 모터가 즉시 운전합니다.
- 정상적인 전환은 이전 PB를 놓고 다른 PB를 누르는 조건입니다. 상대 X의 b접점이 기존 T를 끊어 한시 자기유지를 해제합니다. 전환 버튼을 너무 빨리 놓으면 새 계통도 멈추고 이전 계통이 자동 복구되지 않습니다.
- 두 PB를 계속 함께 누르면 두 X가 여자되고 두 T는 서로 차단됩니다. 두 LS도 감지되면 두 모터가 동시에 운전할 수 있습니다. 원본의 타이머 상호 차단을 모터의 완전한 상호 금지로 바꾸지 않았습니다.
- WL = (X1 여자이고 MC1 소자) 또는 (X2 여자이고 MC2 소자)입니다. 선택된 계통의 모터 대기를 표시합니다.
- 과부하 시 모든 운전 자기유지와 타이머는 해제되고 YL만 지속 점등합니다. 경보 분기는 PB0보다 앞에 있으므로 트립 중 PB0를 눌러도 YL은 켜져 있습니다.

LS는 클릭하면 감지 상태를 유지하고 다시 클릭하면 해제하는 기계적 입력입니다. 전원 OFF에서도 물리적 접점 위치는 감지 상태에 따라 표시합니다. 실제 기계 이동 경로, LS 설치 위치나 두 LS의 물리적 상호 배타성은 도면에 없으므로 가정하지 않았습니다. 타이머는 이상적인 비유지형 온딜레이이며 전원이 끊기면 누적 시간이 복귀합니다. 접점 바운스·코일 응답 공차·모터 관성·실측 전류는 계산하지 않습니다.

원본의 주석과 동작 설명은 회로 판독 자료로 사용했습니다. 사용자 작업 지시와 구별하며 접점 연결을 기준으로 조건별 동작을 해석했습니다.
