# 도면 011 교사용 사용 안내

한시 자기유지 · LS 즉시 기동 · 계통 전환

PB1 또는 PB2를 해당 타이머가 완료될 때까지 누르면 T 한시 a접점으로 자기유지가 성립합니다. 선택된 계통의 LS가 감지되면 해당 모터는 즉시 운전합니다.

## 실행과 조작

ZIP 전체를 압축 해제한 뒤 **index.html**을 Chrome에서 엽니다. 인터넷·설치·계정 없이 실행됩니다. 전체 파일 구성을 유지하세요. 검증 환경은 Windows Chrome입니다.

- **단계별 설명:** 4개 수업, 총 36개 장면입니다. 이전·다음·자동 재생은 설명용 시점을 복원합니다.
- **자유 조작:** 전원·PB·LS·과부하를 직접 조작하며 실제 초 단위 계시를 관찰합니다. 일시정지·재개가 가능합니다.
- **PB 버튼:** 누르고 있는 동안 작동합니다. 마우스·터치 또는 초점을 둔 뒤 Space/Enter를 사용합니다. 버튼 밖에서 놓거나 창을 떠나면 누름을 해제합니다.
- **LS 버튼:** 한 번 클릭하면 감지 유지, 다시 클릭하면 해제합니다.
- **시간 설정:** 입력 후 Tab 또는 다른 곳을 눌러 적용합니다. 운전 중 설정 변경은 수업용 기능입니다.
- **보기:** 전체·제어회로·운전부·경보부를 선택해 확대합니다. 작은 화면에서는 회로 영역 안에서 좌우로 움직입니다.
- **같은 기기 찾기:** 이름을 선택하면 코일과 관련 접점을 함께 강조합니다. 다시 선택하면 강조가 해제됩니다.
- **원본 자료:** PDF 실제 7쪽(11-7) 회로도와 8쪽(11-8) 동작사항을 함께 확인합니다.

초록색은 닫힌 경로를 통한 통전, 파란색은 전원 측 연결, 회색은 비통전입니다. 색과 함께 접점 개폐 및 모터 운전·정지를 표시합니다. a/b는 정상 상태의 접점 종류이며 코일 OFF가 모든 접점 열림을 뜻하지 않습니다. 교류이므로 선 색과 모터 애니메이션은 실제 전류 방향·회전 속도를 뜻하지 않습니다.

## 추천 시연 순서

1. PB1·LS1 수업에서 짧게 누르고 놓는 장면과 T1 완료 후 놓는 장면을 비교합니다. PB1에 병렬인 접점이 X1이 아니라 T1 한시 a임을 찾습니다.
2. 자기유지 후 LS1을 감지·해제합니다. M1만 켜지고 꺼지며 X1·T1은 유지되는 것을 확인합니다.
3. 자유 조작에서 LS1을 먼저 감지시킨 뒤 PB1을 누릅니다. T1 완료 전에도 M1이 즉시 운전하는 것을 확인합니다.
4. 계통 전환 수업에서 PB2가 X2를 여자시키고, X2 b가 T1을 끊어 이전 유지를 해제하는 순서를 살펴봅니다. 새 T2도 완료해야 버튼을 놓을 수 있습니다.
5. 두 PB를 함께 누른 장면에서 두 X는 여자되지만 두 T는 차단되는 것을 비교합니다. 두 LS가 감지되면 이 조건에서 두 모터가 모두 운전합니다.
6. PB0 공통 정지와 과부하 YL 지속 점등을 확인합니다.

## 시간 설정

T1 기본 3초, T2 기본 5초이며 각각 1~30초로 설정합니다. 이 시간은 버튼을 놓아도 유지되기 위한 누름 시간입니다. LS 감지 후 모터를 늦게 기동시키는 시간이 아닙니다. 기본값은 수업 예시이며 원본은 t1·t2로 표기합니다.

## 핵심 설명

- 자기유지 접점은 T1·T2의 한시 a입니다. 설정시간 전 버튼을 놓으면 X와 T가 복귀하고 누적 시간도 0초가 됩니다.
- LS1·LS2는 각 MC에 직접 직렬 연결된 a접점입니다. 감지되면 타이머 완료 여부와 무관하게 현재 공급되는 계통의 모터가 즉시 운전합니다.
- 정상적인 전환은 이전 PB를 놓고 다른 PB를 누르는 조건입니다. 상대 X의 b접점이 기존 T를 끊어 한시 자기유지를 해제합니다. 전환 버튼을 너무 빨리 놓으면 새 계통도 멈추고 이전 계통이 자동 복구되지 않습니다.
- 두 PB를 계속 함께 누르면 두 X가 여자되고 두 T는 서로 차단됩니다. 두 LS도 감지되면 두 모터가 동시에 운전할 수 있습니다. 원본의 타이머 상호 차단을 모터의 완전한 상호 금지로 바꾸지 않았습니다.
- WL = (X1 여자이고 MC1 소자) 또는 (X2 여자이고 MC2 소자)입니다. 선택된 계통의 모터 대기를 표시합니다.
- 과부하 시 모든 운전 자기유지와 타이머는 해제되고 YL만 지속 점등합니다. 경보 분기는 PB0보다 앞에 있으므로 트립 중 PB0를 눌러도 YL은 켜져 있습니다.

## 동작표

| 입력·사건 | 원본 기준 기대 결과와 확인한 동작 |
|---|---|
| PB1 누름, LS1 미감지 | X1·T1·WL ON, M1 대기 |
| T1 설정시간 직전 PB1 놓음 | X1·T1·WL OFF, 시간 0초 |
| T1 완료 후 PB1 놓음 | X1·T1 자기유지, LS1 대기 |
| LS1을 먼저 감지하고 PB1 누름 | T1 완료 전부터 M1·RL 즉시 ON |
| 유지 완료 후 LS1 해제 | M1 OFF, X1·T1 유지, WL ON |
| LS1 재감지 | M1 즉시 ON, 지연을 다시 기다리지 않음 |
| 1번 유지 중 PB2 누름 | 기존 X1·T1·M1 해제, X2·T2 새 기동 |
| PB2 짧게 누른 뒤 놓음 | 새 유지 실패, 이전 계통 자동 복구 없음 |
| 두 PB와 두 LS 모두 작동 | 두 X·모터 ON, 두 T OFF, WL OFF |
| 동시 누름에서 PB1만 놓음 | 1번 소자, T2는 0초부터 계시 |
| PB0 공통 정지 | 두 계통 자기유지·타이머·모터 복귀 |
| 과부하 / 트립 중 PB0 | 운전 부하 OFF, YL 지속 점등 |
| PB를 놓고 EOCR RESET | LS가 감지 상태여도 새 PB 기동 대기 |

## 학생 확인 질문

1. PB1과 병렬인 접점은 왜 X1이 아닌 T1일까요?
2. T1이 완료되기 전에도 M1이 켜지는 조건을 만들어보세요.
3. 상대 버튼을 짧게 눌렀다 놓으면 이전 계통이 돌아오나요?
4. 두 버튼을 함께 누르면 두 타이머와 두 모터는 각각 어떻게 되나요?

## 학습 모델의 범위

LS는 클릭하면 감지 상태를 유지하고 다시 클릭하면 해제하는 기계적 입력입니다. 전원 OFF에서도 물리적 접점 위치는 감지 상태에 따라 표시합니다. 실제 기계 이동 경로, LS 설치 위치나 두 LS의 물리적 상호 배타성은 도면에 없으므로 가정하지 않았습니다. 타이머는 이상적인 비유지형 온딜레이이며 전원이 끊기면 누적 시간이 복귀합니다. 접점 바운스·코일 응답 공차·모터 관성·실측 전류는 계산하지 않습니다.

PB0 또는 트립을 해제할 때 기동 PB를 계속 누르고 있으면 현재 입력을 다시 평가하여 해당 계통이 새로 기동할 수 있습니다. 정지·RESET 수업 장면은 기동 버튼을 놓은 조건입니다. 기존 누적 시간이 복원되는 것은 아닙니다.

이 도면에는 FLS·SS·FR·BZ가 없으므로 해당 조작이나 부저는 포함하지 않습니다.
