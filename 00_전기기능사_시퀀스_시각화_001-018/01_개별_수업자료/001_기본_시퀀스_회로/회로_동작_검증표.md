## 확인한 주요 동작

- 전원 투입 전 모든 부하 OFF, 전원 투입 후 EOCR 전원 공급.
- A 선택 시 FLS에 전원 공급, 감지 시 X·MC1 ON, T·MC2 OFF.
- 자동 운전 중 PB0 누름은 자동 기동 경로를 차단하지 않음.
- 수동 PB1 기동 직후 순시 T 접점 닫힘, 한시 T 접점 열림.
- PB1 놓음 후 자기유지, 설정시간 직전 MC2 OFF, 도달 후 MC2 ON.
- 계시 중 PB0 정지 시 타이머 초기화, 이후 지연 기동 없음.
- 수동에서 자동으로 전환할 때 감지 입력에 따라 정지 또는 M1 운전.
- 자동에서 수동으로 전환하고 PB1을 놓은 상태이면 기동 대기.
- EOCR 트립 시 운전 정지, EOCR 자체 전원과 FR 경보 전원 유지.
- M에서 리셋 후 기동 대기, A 감지 유지 상태에서는 M1 재기동.
- 수동 전원 OFF/ON 후 자기유지 해제, 자동 감지 유지 시 자동 조건 재평가.
- FR의 BZ·YL 교대 경계와 타이머·경보 상태 복원.

## 시각 확인과 수정

- 공개 도면 001의 7페이지를 확대해 접점 기호를 대조했습니다. 제어 접점은 막대형으로 수정하고 PB·SS·EOCR·FR·T 한시 기호를 구별했습니다.
- SS 연동선은 두 접점의 현재 위치를 잇습니다. T 순시·한시 문구는 이름 옆에 두어 옆 배선과 겹치지 않게 했습니다.
- 주접점의 사선 방향, MCCB의 곡선 형태를 반영했습니다. MCCB OFF의 작은 간격은 개방 상태를 보여주기 위한 학습용 표현입니다.
- 기기 선택 강조는 접점 기호 주위로 제한해 이웃 접점의 이름이나 상태를 가리지 않게 했습니다.
- 원본의 좌측 주회로·우측 제어회로 배치를 유지했습니다.
- 통전 선의 강조가 글자 외곽선에 번지던 문제를 수정했습니다.
- 확대 시 다른 영역이 여백에 노출되지 않도록 표시 범위를 제한했습니다.
- 작은 화면에서 회로를 지나치게 축소하지 않고 회로 영역 안에서 좌우로 이동하도록 했습니다.
- 교실 화면 높이에 맞춰 조작부와 설명 영역을 압축 배치했습니다.

검사 코드, 브라우저 결과와 화면 캡처는 `검증` 폴더에 보관합니다. 실제 부품 모델의 시간 접점 구성, FR 초기 위상, FLS 전극 조건은 현물과 대조할 항목입니다.

접점 전용 검증은 `검증/contact-symbol-check.cjs`, 결과는 `검증/contact-symbol-results.json`에 보관했습니다. 수정 전 파일은 `검증/접점수정_이전`에 있습니다. 정상·이상 동작 판정은 위의 검증 범위에 한하며, 모든 실제 기기의 동작을 보증하는 것은 아닙니다.
