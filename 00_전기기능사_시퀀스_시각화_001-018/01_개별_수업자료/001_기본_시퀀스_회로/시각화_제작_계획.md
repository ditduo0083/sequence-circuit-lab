# FLS 회로 동작 시각화 제작 계획

작성일: 2026-09-14  
작업 위치: `2026년 2학기/2학기 실습 관련/FLS_회로_동작_시각화`  
현재 단계: 시제품 01 구현 및 검증 완료 (2026-09-14). 실행 파일은 `index.html`, 사용 방법은 `교사용_사용안내.md`, 검증 결과는 `회로_동작_검증표.md`에 정리했다. 아래 본문은 최초 제작 계획을 보존한 기록이다.

## 1. 제안하는 결과물

**교사가 버튼을 조작하면 원본 회로도의 접점, 통전 경로, 코일, 모터와 램프가 함께 바뀌는 대화형 수업 자료**를 제작한다. 학생이 “무엇이 켜졌는가”뿐 아니라 “어떤 접점 때문에 켜졌는가”를 설명할 수 있게 하는 것이 목적이다.

주 결과물은 교실 PC에서 브라우저로 열어 사용하는 오프라인 자료로 한다. 별도 계정이나 인터넷 연결 없이 실행하도록 구성한다. 우선 교사의 큰 화면 시연을 기준으로 만들고, 같은 자료에서 학생이 자유롭게 조작하는 기능을 제공한다.

| 형식 | 활용 | 우선순위 |
|---|---|---|
| 대화형 회로 시뮬레이터 | 조작에 따라 회로와 기기 상태를 함께 관찰 | 1차 제작 |
| 주요 장면 정지 화면과 설명 카드 | 수업 정리, 인쇄, 기존 수업 자료에 삽입 | 시뮬레이터 검증 후 |
| 수업 활동지·확인 문제 | 다음 동작 예측, 전류 경로 설명 | 2차 확장 |
| 녹화 영상 | 복습용으로 동일한 설명을 재생 | 필요할 때 확장 |

## 2. 참고자료와 해석 범위

- `참고자료/01_회로도.png`: 사용자가 제공한 첫 번째 이미지. 연결 관계와 접점 종류를 판독하는 기준 자료.
- `참고자료/02_동작설명.png`: 사용자가 제공한 두 번째 이미지. 수업 장면과 설명 문장을 구성하는 자료.
- 첨부자료의 문구와 NOTE는 회로에 관한 참고 내용으로 취급한다. 이번 작업의 범위는 사용자가 요청한 시각화 제작 계획이다.
- 상위 폴더의 `과제도면_FLS.jpg`는 별도 실습 사진으로 확인했다. 같은 FLS 명칭만으로 이번 회로와 동일하다고 보거나 회로를 혼합하지 않는다.

현재 계획의 동작 해석은 제공된 이미지에 근거한다. 구현 첫 단계에서 확대 원도와 대조하여 접점 판독을 확정한다. 특히 타이머의 두 접점은 **PB1과 병렬인 순시 a접점**과 **MC2 앞의 한시 a접점**으로 구분하여 검증한다. 실제 부품의 단자 번호나 제품별 설정값은 이 이미지로 확정하지 않는다.

## 3. 학생의 학습 목표

1. 코일과 같은 이름을 가진 접점이 회로도 여러 곳에서 함께 바뀐다는 것을 설명한다.
2. 자동 운전에서 FLS와 X를 거쳐 M1이 동작하는 경로를 찾는다.
3. 수동 운전에서 PB1을 놓아도 운전이 유지되는 이유를 T의 순시 접점으로 설명한다.
4. 타이머 T의 여자와 설정시간 경과를 구분하고, M2가 늦게 동작하는 이유를 설명한다.
5. EOCR 동작 시 운전 회로는 차단되지만 경보 회로는 동작하는 이유를 설명한다.

## 4. 화면 구성

16:9 교실 화면을 기준으로 회로도에 가장 넓은 공간을 배정한다.

```text
┌────────────────────────────────────────────────────────────┐
│ 장면: 자동 / 수동 / 과부하     재생·정지 / 이전·다음 단계     │
├─────────────────────────────────────────┬──────────────────┤
│                                         │ 조작부           │
│ 원본 배치를 유지한 회로도                │ MCCB / SS A·M    │
│                                         │ PB1 / PB0        │
│ 주회로와 제어회로                         │ FLS 감지 / EOCR  │
│ 접점 개폐·코일·통전 경로 동시 표시        ├──────────────────┤
│                                         │ 동작 결과        │
│ 전체 보기 / 관련 회로 확대               │ M1·M2 / 램프·BZ  │
│                                         │ T 경과시간       │
├─────────────────────────────────────────┴──────────────────┤
│ 지금의 원인과 결과 한 문장 + 현재 단계 표시                  │
└────────────────────────────────────────────────────────────┘
```

- 회로도 영역 약 75%, 조작·결과 영역 약 25%를 시작점으로 삼는다. 투사 화면에서 기호가 작으면 관련 회로를 확대한다.
- 자동 장면은 FLS·X·MC1을, 수동 장면은 PB0·PB1·T·MC1·MC2를, 경보 장면은 EOCR·FR·YL·BZ를 중심으로 보여준다.
- 확대해도 원본에서의 위치를 알 수 있게 전체 보기로 즉시 돌아갈 수 있도록 한다.
- 기기를 선택하면 같은 이름의 코일과 모든 관련 접점을 함께 강조한다. 예: X 선택 → X 코일, MC1 공급 분기의 X a접점, T 앞의 X b접점.
- 화면 설명은 한 번에 한 문장으로 제한한다. 예: “X가 여자되어 X의 a접점이 닫히고 MC1 코일에 전원이 공급됩니다.”
- 부품 이름은 `MC1 전자접촉기`, `T 타이머`처럼 기호와 한글을 함께 표시한다.

## 5. 동작을 표현하는 규칙

| 대상 | 화면 표현 | 학생이 파악할 내용 |
|---|---|---|
| 전선 | 기본 회색, 전압이 걸린 구간과 부하를 포함한 통전 경로의 강조를 구분 | 전압 존재와 실제 통전은 같은 뜻이 아님 |
| 접점 | 접점 기호 자체를 열고 닫으며 `열림/닫힘` 표시 | 선의 색만 바뀌는 것이 아니라 접점 상태가 바뀜 |
| 코일 | 여자 시 강조하고 `여자/소자` 표시 | 접점을 움직이는 원인 |
| 같은 이름의 접점 | 해당 코일과 함께 강조 | 떨어져 그려진 기호가 같은 기기의 일부임 |
| M1·M2 | 회전 표시와 `운전/정지`를 함께 표시 | 주접점과 모터 운전의 관계 |
| RL·GL·YL | 도면의 적·녹·황 램프색과 기호를 유지 | 색뿐 아니라 기호로 상태 식별 |
| T | `계시 중/설정시간 도달`과 경과시간 표시 | 순시 접점과 한시 접점의 차이 |
| FR·BZ·YL | BZ와 YL의 교대 상태를 표시 | 경보가 번갈아 동작하는 관계 |

색 이외에 접점 모양과 상태 글자를 반드시 병행한다. 부저는 눈에 보이는 동작 표시를 기본으로 하고, 소리는 교사가 켤 수 있게 한다.

회로는 교류이므로 선을 따라 한 방향으로 점이 이동하는 표현을 실제 전류 방향처럼 사용하지 않는다. 통전 강조를 중심으로 표현한다. PE 접지선을 정상 운전 전류의 귀로처럼 강조하지 않는다.

설명을 위한 단계 분해는 실제 접점 사이에 긴 시간차가 있다는 의미가 아니다. 실제로 거의 함께 일어나는 변화도 학습을 위해 나누어 보여준다. 반면 T의 설정시간과 FR의 교대 간격은 모델의 시간 조건으로 구분한다.

## 6. 필수 수업 장면

### 장면 A. 전원 투입과 대기

1. MCCB OFF: 전체 무전원 상태.
2. MCCB ON: EOCR에 전원이 공급되는 경로 표시.
3. 기동 조건이 없으면 모터는 정지 상태임을 확인.

첫 화면의 시연 초기값은 `MCCB OFF, SS=M, 버튼을 누르지 않음, FLS 감지 해제, EOCR 정상`으로 둔다. 초기값은 수업을 위한 선택이며 도면에 명시된 설정으로 표현하지 않는다.

### 장면 B. 자동 운전

| 순서 | 조작·조건 | 강조할 원인과 결과 |
|---|---|---|
| 1 | SS=A | FLS 전원 공급, 감지 대기 |
| 2 | FLS 감지 동작 | FLS 접점 닫힘 → X 여자 |
| 3 | X 접점 변화 | X a접점 닫힘 → MC1 여자 → M1 운전, RL 점등 |
| 4 | 같은 순간의 X b접점 관찰 | T 앞의 X b접점 열림 → T와 MC2는 동작하지 않음 |
| 5 | FLS 감지 해제 | X 소자 → MC1 소자 → M1 정지, RL 소등 |

자동 운전의 핵심 질문: “M1은 도는데 M2는 왜 돌지 않을까?”

1차 버전은 FLS를 `감지/해제`로 조작한다. 수조 그림과 수위 슬라이더는 실제 급수·배수 용도 및 전극 동작 조건을 확인한 뒤 확장한다. E1·E2·E3가 있다고 해서 특정 수위에서 반드시 기동한다고 단정하지 않는다.

### 장면 C. 수동 운전과 시간 지연

| 순서 | 조작·조건 | 강조할 원인과 결과 |
|---|---|---|
| 1 | SS=M | PB0 b접점 닫힘, PB1 기동 대기 |
| 2 | PB1 누름 | MC1과 T 여자 → M1 운전, RL 점등 |
| 3 | T의 순시 접점 관찰 | PB1과 병렬인 T 접점이 닫혀 자기유지 경로 형성 |
| 4 | PB1 놓음 | PB1은 열리지만 T 순시 접점 경로로 운전 유지 |
| 5 | T 설정시간 경과 | T 한시 a접점 닫힘 → MC2 여자 → M2 운전, GL 점등 |
| 6 | PB0 누름 | 수동 공급 경로 개방 → T·MC1·MC2 소자, 두 모터 정지 |
| 7 | PB0 놓음 | PB1을 누르지 않으면 정지 유지 |

타이머 예시값은 5초로 제안하되 화면에 `수업 예시 설정`임을 표시한다. 도면에는 t초로만 제시되어 있다. 실제 실습 설정값이 정해지면 교사가 변경할 수 있게 한다.

### 장면 D. 과부하와 경보

1. 운전 중 `과부하 발생`을 조작한다.
2. EOCR의 운전 회로용 b접점이 열리고 MC1·MC2가 소자되어 모터가 정지한다.
3. EOCR의 경보용 a접점이 닫혀 FR에 전원이 공급되는 별도 경로를 강조한다.
4. 설명자료에 따라 BZ 동작부터 시작하고, FR 설정 간격에 맞춰 BZ와 YL이 교대로 동작하도록 구성한다. 초기 위상은 실제 사용 부품 확인 시 대조한다.
5. EOCR RESET 후 경보가 해제되고, 현재 SS·FLS·버튼 조건에 따라 운전 가능 상태를 다시 계산한다.

EOCR 자체 전원과 경보 분기는 운전 차단 접점 앞에서 공급되므로 과부하 시 화면 전체를 무전원으로 표시하지 않는다. MCCB OFF와 EOCR 트립의 차이를 보여준다.

## 7. 설명문을 그대로 단순화하면 안 되는 부분

| 쟁점 | 도면을 바탕으로 한 계획상의 처리 |
|---|---|
| 수동 운전 중 SS를 A로 돌리면 “모두 정지” | 수동 회로는 끊기지만 FLS 감지가 성립하면 자동 경로에서 MC1이 여자될 수 있다. 감지 해제/감지 동작 두 조건을 따로 시연한다. 전환 순간의 실제 기계적 지연은 별도 모델링하지 않는다. |
| EOCR RESET하면 “초기 상태 복귀” | 경보 해제와 운전 조건 재평가로 표현한다. A 위치에서 감지 조건이 유지되면 M1이 다시 운전할 수 있으므로 항상 정지 유지로 고정하지 않는다. |
| PB0를 누르면 모든 운전이 정지하는가 | PB0는 수동 분기에 있다. 도면상 자동 운전 경로에는 직렬로 들어 있지 않으므로 자동 운전까지 무조건 정지시키는 논리를 추가하지 않는다. |
| 같은 T 이름의 접점은 동시에 닫히는가 | 자기유지용 순시 접점과 MC2용 한시 접점을 구분한다. PB1을 놓는 장면을 통해 차이를 확인한다. |
| FLS 감지 상태와 특정 수위의 관계 | 실제 전극 설정과 운전 목적을 확인하기 전에는 감지 ON/OFF만 모델링한다. |
| 모터 정지가 곧 회로 전체 무전원인가 | EOCR 전원, FLS 전원, 경보 회로 등은 현재 조건에 따라 따로 표시한다. |

일반적인 도면 논리 상태를 학습하는 자료로 만들며, 전류 크기·모터 속도·열적 과부하 곡선을 계산하는 해석기로 확장하지 않는다.

## 8. 교사 시연과 학생 활동

### 교사 설명 모드

- `전원 투입 → 자동 운전 → 수동 운전 → 과부하`의 안내 장면을 제공한다.
- 이전·다음 단계, 재생·일시정지를 제공한다.
- 일시정지하면 T와 FR의 수업용 시간도 함께 멈춰 설명 중 상태가 바뀌지 않게 한다.
- 이전 단계는 저장한 상태로 돌아가게 하여 타이머와 접점 상태도 일관되게 복원한다.
- 현재 단계에서 바뀐 기기만 강조하고 원인과 결과를 한 문장으로 보여준다.

### 학생 조작 모드

- MCCB, SS, PB0, PB1, FLS 감지, EOCR 트립·리셋을 자유롭게 조작한다.
- PB0·PB1은 누름과 놓음이 구분되는 순간동작 버튼으로 구현한다. 마우스·터치·키보드에서 놓음이 누락되지 않게 한다.
- `다음에 닫힐 접점은?`, `M2가 아직 돌지 않는 이유는?`처럼 짧은 예측 질문을 제시한다.
- 정답 확인 시 결과뿐 아니라 해당 경로를 표시한다.

### 50분 수업 운영 예시

| 시간 | 활동 |
|---|---|
| 0~5분 | 기호와 주회로·제어회로 구분 |
| 5~15분 | 자동 운전 시연, X 접점 찾기 |
| 15~30분 | 수동 기동, PB1 놓기, 자기유지와 시간 지연 |
| 30~40분 | EOCR 트립, 경보 교대, 리셋 |
| 40~50분 | 다음 동작 예측, 학생이 회로 경로를 설명 |

학습 확인 예시: “PB1을 놓은 뒤에도 M1이 도는 경로를 짚어 설명하세요.” / “자동 운전에서는 T 앞의 어떤 접점이 열리나요?” / “과부하인데 부저에 전원이 공급되는 이유는 무엇인가요?”

## 9. 제작 순서와 단계별 완료 기준

| 단계 | 제작 내용 | 완료 기준 |
|---|---|---|
| 1. 회로 논리 정리 | 접점 목록, 코일 연결, 전원 분기, 상태 전이 정리 | 원본과 연결 관계가 대응하고 해석이 불명확한 항목이 구분됨 |
| 2. 회로도 재작성 | 원본 배치를 유지한 확대 가능한 SVG 회로도 제작 | 접점·코일·전선 구간을 각각 선택하고 강조할 수 있음 |
| 3. 핵심 동작 구현 | 전원, 자동, 수동, 자기유지, T 지연, EOCR·FR 구현 | 아래 검증 시나리오의 기기 상태와 통전 경로가 일치함 |
| 4. 설명 화면 구성 | 단계 진행, 확대, 한 문장 설명, 상태 표시 연결 | 한 번의 조작에 회로·결과·설명이 같은 상태로 바뀜 |
| 5. 수업용 점검 | 큰 화면 가독성, 입력 방법, 오프라인 실행 확인 | 교사가 파일을 열어 각 장면을 시연하고 일시정지할 수 있음 |

구현은 HTML/CSS/JavaScript와 SVG를 기본으로 한다. 회로 상태 계산과 화면 애니메이션을 분리하여, 그려지는 순서 때문에 논리가 달라지지 않게 한다. 외부 서비스와 외부 글꼴에 의존하지 않는다. 1차 배포본은 더블클릭으로 열리는 `index.html`을 목표로 한다.

원본 이미지 위에 색만 덧씌우면 접점의 열린 모양이 남는 문제가 있으므로, 핵심 회로는 조작 가능한 선과 기호로 다시 작성한다. 원본 이미지도 함께 보관하여 대조할 수 있게 한다.

## 10. 구현 시 확인할 시나리오

아래는 계획 단계의 검증 항목이며 아직 실행한 테스트 결과가 아니다. 정상 접점과 정상 부품을 전제로 한다.

| 조건·조작 | 기대 상태 |
|---|---|
| MCCB OFF | 코일·모터·램프·부저 무전원 |
| MCCB ON, M, PB1 놓음 | EOCR 전원 ON, 모터 정지 |
| A, FLS 감지 해제 | FLS 전원 ON, X·MC1·MC2 OFF |
| A, FLS 감지 동작 | X·MC1·RL ON, T·MC2·GL OFF |
| 자동 운전 중 FLS 감지 해제 | X·MC1 OFF, M1 정지 |
| 자동 운전 중 PB0 누름 | 감지 유지 시 자동 운전 경로 유지 |
| M, PB1 누름 | T·MC1·RL ON, 시간 도달 전 MC2 OFF |
| M, 설정시간 전 PB1 놓음 | T의 순시 접점을 통한 자기유지 |
| M, 설정시간 도달 | MC2·GL ON, M1·M2 운전 |
| 계시 중 PB0 누름 | T 리셋, MC1 OFF, 이후 MC2가 뒤늦게 켜지지 않음 |
| 두 모터 운전 중 PB0 누름·놓음 | 두 모터 정지, PB1 재조작 전 정지 유지 |
| 수동 운전 중 A 전환, FLS 해제 | 모터 정지 |
| 수동 운전 중 A 전환, FLS 감지 | 자동 조건 재평가 후 M1 운전 가능, T·MC2 OFF |
| 자동 운전 중 M 전환, PB1 놓음 | 자동 경로 해제 후 수동 기동 대기 |
| 운전 중 EOCR 트립 | 운전 코일 OFF, FR ON, BZ·YL 교대 동작 |
| EOCR 트립 유지 중 PB1 누름 | 모터 기동 안 됨 |
| EOCR RESET, M, PB1 놓음 | 경보 해제, 수동 기동 대기 |
| EOCR RESET, A, FLS 감지 | 경보 해제, 자동 조건에 따라 M1 운전 가능 |
| 운전 중 MCCB OFF 후 ON, M, PB1 놓음 | 자기유지 해제, 기동 대기 |
| 운전 중 MCCB OFF 후 ON, A, FLS 감지 | 자동 조건에 따라 M1 운전 가능 |
| 일시정지·이전 단계·다시 재생 | T·FR 시간, 접점, 램프와 설명이 동일한 시점 유지 |

## 11. 산출물과 후속 확장

현재 저장한 자료:

```text
FLS_회로_동작_시각화/
  시각화_제작_계획.md
  참고자료/
    01_회로도.png
    02_동작설명.png
```

다음 제작 단계의 예정 산출물:

- `index.html`: 오프라인 수업용 실행 화면.
- `교사용_사용안내.md`: 실행 방법, 장면별 핵심 설명, 예시 설정값.
- `회로_동작_검증표.md`: 시나리오별 실제 검증 결과와 남은 확인 사항.

1차 완성 범위는 자동·수동·과부하, 경로 강조, 접점 개폐, 단계별 설명이다. 수조 애니메이션, 실제 기구 사진 연결, 단자 번호 퀴즈, 오배선 찾기, 활동지와 영상은 핵심 동작을 검증한 뒤 확장한다.
