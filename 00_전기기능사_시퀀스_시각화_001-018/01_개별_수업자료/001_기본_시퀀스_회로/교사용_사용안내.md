# 회로가 보이는 교실 — FLS 시퀀스

도면 ① · 접점 기호 개선 · 2026-09-15

## 실행

이 폴더의 **index.html을 Chrome 또는 Edge에서 열면 실행됩니다.** 인터넷 연결과 별도 설치가 필요하지 않습니다. 다른 PC로 옮길 때는 index.html만 가져가지 말고, 같은 폴더의 CSS·JavaScript 파일을 함께 복사하세요. 배포용 ZIP도 같은 구성을 담고 있습니다.

## 먼저 볼 장면

1. 상단에서 **수동 운전**을 선택합니다.
2. 회로 위쪽의 **운전부**를 눌러 확대합니다.
3. **다음 단계**를 눌러 PB1 누름, PB1 놓음, 타이머 계시, M2 기동을 차례로 확인합니다.
4. 아래 **T** 버튼을 선택하면 코일과 순시·한시 접점을 함께 찾을 수 있습니다.

자동 운전과 과부하 경보도 각각 7단계로 구성되어 있습니다. 이전 단계나 하단 단계 번호로 자유롭게 이동할 수 있습니다.

## 접점 기호 읽기

공개 도면 001의 7페이지를 기준으로 일반 접점을 막대형으로 표현했습니다. PB는 누름 표시, SS는 선택 표시와 점선 연동, EOCR은 × 표시, FR은 마름모, T 한시 접점은 삼각형 표시를 유지합니다. T 순시 접점에는 한시 표시가 없습니다. 주회로 접촉기는 원본 방향의 사선 접점, MCCB는 곡선 기호를 사용합니다.

화면은 현재 동작 상태를 보여줍니다. 열린 제어 접점은 고정 단자 오른쪽에 막대가 떨어져 있고, 닫힌 접점은 두 단자에 연결됩니다. 따라서 여자된 장면은 무여자 기준으로 그린 정지 도면과 접점 위치가 달라집니다. a·b라는 접점 종류는 유지하고, 현재 상태를 별도로 열림·닫힘으로 표시합니다. 색은 통전 여부를 뜻하며 실제 교류의 한 방향 흐름을 뜻하지 않습니다.

접점 기호 수정 전후의 동작 모델은 동일합니다. 수동 기동 후 T 순시 접점의 자기유지, 설정시간 후 MC2 추가 기동, 자동의 M1 운전, FR의 BZ·YL 교대 경보를 유지합니다. 이 자료는 회로 논리 학습용이며 실제 부품을 연결한 시험이나 기계적인 접점 이동거리의 재현은 아닙니다.

## 단계별 설명과 자유 조작

| 기능 | 단계별 설명 | 자유 조작 |
|---|---|---|
| 진행 방법 | 이전·다음 단계 또는 자동 재생 | 오른쪽 스위치·버튼 직접 조작 |
| 시간 | 설명용 예시 시점으로 이동 | 실제 초 단위로 T와 FR 계시 |
| 자동 재생 | 4초마다 다음 설명 장면으로 이동 | 시간 일시정지 / 재개 |
| 기동·정지 버튼 | 현재 장면의 누름 상태 표시 | 누르는 동안 동작, 놓으면 원위치 |
| 처음으로 | 선택한 설명 장면의 1단계 | 전원 OFF, SS=M, 감지 해제, 트립 해제 |

자유 조작 전환 시 현재 회로 상태를 이어받습니다. PB0·PB1은 놓은 상태로 시작합니다. 자유 조작에서 시간을 멈춰도 스위치와 버튼은 조작할 수 있습니다. 다른 탭으로 이동하거나 원본 자료를 열면 시간이 일시정지됩니다.

## 자유 조작 예시

### 자동 운전

`자유 조작으로 전환 → 처음으로 → MCCB ON → A 자동 → FLS 감지`

M1과 RL이 동작합니다. X가 여자되어 a접점은 닫히고 T 앞의 b접점은 열립니다. FLS를 해제하면 M1이 정지합니다. PB0는 수동 분기에 있으므로 자동 운전은 PB0로 정지하지 않습니다.

### 수동 운전

`처음으로 → MCCB ON → M 수동 → PB1을 잠깐 누르고 놓음`

M1이 먼저 운전합니다. PB1을 놓아도 T의 순시 접점이 자기유지합니다. 기본 예시값인 5초 뒤 M2와 GL이 켜집니다. PB0를 누르면 두 모터와 타이머가 정지합니다.

PB0·PB1은 마우스로 누르거나, Tab으로 이동한 후 Space·Enter를 누르고 놓을 수 있습니다. 누른 채 버튼 밖으로 이동해 놓아도 누름 상태가 해제됩니다.

### 과부하 경보

운전 중 **EOCR 과부하**를 누릅니다. 모터가 정지하고 BZ와 YL이 기본 1초 간격으로 번갈아 동작합니다. **RESET**은 트립을 해제한 뒤 현재 운전 조건을 다시 평가합니다.

- M 위치에서 PB1을 놓고 리셋하면 수동 기동 대기입니다.
- A 위치에서 FLS 감지를 유지한 채 리셋하면 M1이 다시 운전할 수 있습니다.

## 표시와 설정

- 청록색 굵은 선: 부하가 포함된 통전 경로.
- 파란색 얇은 선: 전원 측에 연결되었으나 해당 구간에 부하 전류 경로가 완성되지 않은 부분.
- 회색 선: 비통전 구간. PE 접지선은 정상 통전 경로로 강조하지 않습니다.
- 접점 옆에 **a/b, 순시/한시, 열림/닫힘**을 함께 표시합니다.
- 주회로의 MC1·MC2와 제어회로의 코일·보조접점은 같은 기기 선택으로 함께 강조됩니다.
- T 설정은 1~30초, FR 교대 간격은 0.5·1·2초 중 선택할 수 있습니다. 모두 수업 예시값입니다.
- 소리는 기본 OFF입니다. **소리 ON**을 선택하면 시간이 진행되는 BZ 동작 구간에 소리가 납니다.
- **전체 화면** 또는 브라우저 F11로 화면을 넓힐 수 있습니다. 작은 화면에서는 회로 영역을 좌우로 밀어 볼 수 있습니다.
- **원본 자료**에서 제공된 회로도와 동작 설명을 나란히 대조할 수 있습니다.

## 모델의 범위

제공된 이미지의 연결 관계를 바탕으로 정상 접점과 이상적인 릴레이 동작을 표현한 학습용 모델입니다. PB1 병렬 T는 순시 a접점, MC2 앞 T는 한시 a접점으로 구분했습니다. 실제 부품의 단자 번호·세부 동작 설정은 포함하지 않았습니다.

FLS는 감지/해제 입력만 제공합니다. 특정 수위에서의 급수·배수나 전극 높이는 가정하지 않았습니다. EOCR 과부하는 버튼으로 발생시키며 전류·열적 과부하 곡선을 계산하지 않습니다. FR의 예시 초기 위상은 BZ부터입니다. 실제 부품 설정과 대조할 때 이 항목을 확인하면 됩니다.

모드 전환 시 접점은 이전 경로를 끊은 후 새 조건을 평가하며, 실제 릴레이의 기계적 지연은 별도로 재현하지 않습니다.

## 수정할 때 볼 부분

실제 수업 화면을 보면서 글자 크기, 회로 확대 범위, 통전 강조색, 단계 설명 문장과 순서를 우선 조정하면 됩니다. 현재 단계에서는 수조 애니메이션과 단자 번호 퀴즈를 추가하지 않았습니다.
