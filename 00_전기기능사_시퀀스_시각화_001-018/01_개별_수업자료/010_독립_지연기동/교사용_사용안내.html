도면 010 교사용 사용 안내

LS 감지 · 두 계통 독립 지연 기동

PB1·LS1·T1이 M1을, PB2·LS2·T2가 M2를 각각 제어합니다. 두 계통은 독립적으로 운전할 수 있습니다. PB0는 공통 정지이며, 과부하 때는 YL만 지속 점등합니다.

실행과 조작

ZIP 전체를 압축 해제한 뒤 index.html을 Chrome에서 엽니다. 인터넷·설치·계정 없이 실행됩니다. 전체 파일 구성을 유지하세요. 검증 환경은 Windows Chrome입니다.

  • 단계별 설명: 32개 장면을 이전·다음·자동 재생으로 이동합니다. 장면은 예시 시점을 복원하므로 실제 초 단위 계시와 구별합니다.
  • 자유 조작: 전원·기동·정지·감지·과부하를 직접 조작합니다. 시간 일시정지·재개로 접점을 설명할 수 있습니다.
  • PB 버튼: 누르고 있는 동안 동작합니다. 마우스·터치, 또는 초점을 둔 뒤 Space/Enter를 사용할 수 있습니다. 버튼 밖에서 놓거나 창을 떠나면 누름이 해제됩니다.
  • 감지 버튼: 클릭하면 감지 상태가 유지되고 다시 클릭하면 해제됩니다.
  • 시간 설정: 입력 뒤 Tab 또는 다른 곳을 눌러 적용합니다. 운전 중 설정 변경은 수업용 기능이며 실제 기기의 변경 절차를 재현하지 않습니다.
  • 보기: 전체·제어회로·운전부·경보부로 확대합니다. 휴대전화에서는 도면을 좌우로 밀어 살펴봅니다.
  • 같은 기기 찾기: 해당 이름의 코일과 접점을 함께 강조합니다. 원본 자료에서 PDF의 실제 7쪽(11-7) 회로도와 8쪽(11-8) 동작사항을 비교합니다.

초록색은 닫힌 경로를 통한 통전, 파란색은 전원 측 연결, 회색은 비통전입니다. 색과 함께 접점의 열림·닫힘, 모터의 운전·정지 상태를 표시합니다. a/b는 정상 상태의 접점 종류이며 코일 OFF가 모든 접점 열림을 뜻하지 않습니다. 교류 회로이므로 색과 모터 회전 애니메이션은 실제 전류 방향·속도를 뜻하지 않습니다.

추천 시연 순서

  1. PB1·LS1 수업에서 PB1 누름 → X1 자기유지·WL 점등 → LS1 감지 → T1 계시 → M1·RL 운전을 봅니다.
  2. LS1을 해제하면 M1이 멈추지만 X1이 남는 장면을 확인합니다. LS1만 다시 감지시켜 T1이 0초부터 시작하는 이유를 설명합니다.
  3. PB2·LS2 수업에서 같은 원리로 2번 계통을 조작합니다.
  4. 함께 조작 수업에서 M1 운전 중 PB2만 누릅니다. M1이 운전 중이어도 WL이 켜지는 이유를 두 병렬 경로로 설명합니다.
  5. 두 모터 동시 운전 → LS1만 해제 → M2 유지 → PB0 전체 정지 순서로 독립 입력과 공통 정지를 비교합니다.

시간 설정

T1 기본 3초, T2 기본 5초는 각각 LS 감지 후 모터가 켜지기까지의 지연입니다. 두 시간을 1~30초 범위에서 따로 설정합니다. 원본은 t1·t2로만 설명하므로 기본값은 수업 예시입니다. 시간 간 대소 관계 제한은 없습니다. LS 감지를 해제하면 해당 시간은 즉시 0초로 복귀합니다.

핵심 설명

  • X1·X2는 각각 PB1·PB2를 우회하는 자기유지 a접점을 갖습니다. LS 감지 전에 운전 준비가 필요합니다.
  • LS1·LS2는 감지 시 닫히는 a접점입니다. 원본의 사각형 가동부로 표현했고 감지에 따라 움직입니다.
  • LS 해제는 해당 T·MC만 복귀시키며 X 자기유지는 남습니다. 재감지만으로 새 지연을 시작합니다.
  • WL = (X1 여자이고 M1 정지) 또는 (X2 여자이고 M2 정지)입니다. 한 모터가 운전 중이어도 다른 준비 계통이 대기하면 WL은 켜집니다. 두 모터가 모두 운전 중이면 WL은 꺼집니다.
  • 두 모터를 상호 금지하는 접점은 원본에 없습니다. 화면에서도 두 계통의 동시 운전을 허용합니다.
  • PB0는 공통 운전선에 있어 두 계통의 자기유지를 모두 해제합니다. 감지 입력이 남아 있어도 PB1·PB2를 놓았다면 자동 재기동하지 않습니다.
  • 트립 시 YL만 켜집니다. 경보 분기가 PB0보다 앞에 있으므로 트립 중 PB0를 눌러도 YL은 유지됩니다. 원본에 FLS·SS·FR·BZ가 없어 해당 조작과 부저 소리는 넣지 않았습니다.

학생 확인 질문

  1. LS만 감지시키면 왜 모터가 켜지지 않나요?
  2. LS 해제와 PB0 정지는 자기유지에 어떤 차이를 만드나요?
  3. M1이 운전 중인데 WL이 켜지는 경우를 직접 만들어보세요.
  4. 원본에서 두 모터의 동시 운전을 금지하는 접점이 있는지 찾아보세요.

학습 모델의 범위

LS는 클릭할 때마다 감지 상태를 유지하거나 해제하는 입력입니다. 접점의 물리적 감지 상태는 전원 OFF에서도 표시합니다. 실제 기계의 이동 경로, LS1·LS2 설치 위치나 물리적 상호 배타 관계는 도면에 없으므로 가정하지 않았습니다. 두 타이머는 이상적인 비유지형 온딜레이입니다. 실제 접점 바운스나 코일 소자 지연은 계산하지 않습니다.

접점 개폐·코일 여자·통전 경로를 보여주는 학습 모델이며 실측 전류, 모터 관성이나 기기 시간 공차는 계산하지 않습니다. PB를 계속 누른 상태에서 정지·트립을 해제하면 현재 입력을 다시 평가하므로 해당 계통이 새로 기동할 수 있습니다. 정지·RESET 설명 장면은 기동 버튼을 놓은 조건입니다.
