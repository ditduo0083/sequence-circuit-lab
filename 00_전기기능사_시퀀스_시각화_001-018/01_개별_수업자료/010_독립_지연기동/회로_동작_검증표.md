## 브라우저 확인 사항

- 이전 단계의 계시·접점 복원
- 설명 장면 자동 재생과 정지
- PB1 자기유지와 LS 미감지 대기
- LS1 감지·T1 일시정지·완료 후 M1
- M1 운전+2번 대기에서 WL 점등
- LS2 키보드 감지·T2 후 두 모터 동시 운전
- LS1 해제는 M1·T1만 복귀하고 X1 유지
- PB1 재누름 없이 LS1 재감지 후 기동
- PB0 공통 정지·LS 유지 중 기동 대기
- 과부하 YL 지속·PB0로 경보 차단 안 됨
- 감지 유지 중 RESET도 PB1·PB2 대기
- FLS·SS·FR·BZ 조작을 LS 화면에서 제거
- LS 원본 사각 접점과 관련 기기 강조
- 기동 버튼 창 이탈·버튼 밖 놓기 해제
- 입력 중 설정값 보존
- 원본 회로도·동작사항 이미지 열기
- 360px 본문 가로 넘침 없음
- 1366×768 한 화면 배치
- 1920×1080 화면
- 오프라인 실행·외부 요청 없음
