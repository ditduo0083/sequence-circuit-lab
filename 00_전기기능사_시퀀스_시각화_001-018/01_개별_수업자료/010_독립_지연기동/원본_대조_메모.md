## 연결과 판독

전원 → EOCR 운전 b → 공통 PB0 b 뒤에서 두 계통과 표시등 전원이 나뉩니다. 1번은 (PB1 a ∥ X1 유지 a) 뒤에서 X1 코일, LS1 a → T1 코일, T1 한시 a → MC1로 분기합니다. 2번은 PB2·X2·LS2·T2·MC2로 같은 구조입니다. WL은 (X1 a → MC1 b)와 (X2 a → MC2 b)의 병렬 합류 뒤에 있습니다. RL·GL은 각각 MC 보조 a로 공급합니다. EOCR 경보 a → YL 분기는 운전 b와 PB0보다 앞에서 공급합니다.

| 접점 | 구동·입력 | 정상 상태 | 연결 노드 | 동작 조건·역할 |
|---|---|---|---|---|
| EOCR 운전 b / 경보 a | EOCR | 정상 닫힘 / 열림 | run / YL | 트립 시 운전 차단·YL 공급 |
| PB0 b | 공통 누름 버튼 | 미누름 닫힘 | run → stopOut | 두 계통 전체 정지 |
| PB1 a / X1 유지 a | PB1 / X1 | 미누름·소자 시 열림 | branch1 → hold1 | 1번 기동·자기유지 |
| PB2 a / X2 유지 a | PB2 / X2 | 미누름·소자 시 열림 | branch2 → hold2 | 2번 기동·자기유지 |
| LS1 a / LS2 a | 기계적 감지 입력 | 미감지 열림 | fork1 → T1 / fork2 → T2 | 감지 시 해당 타이머 계시 |
| T1 한시 a / T2 한시 a | T1 / T2 | 미완료 열림 | fork1 → MC1 / fork2 → MC2 | 해당 지연 완료 후 모터 기동 |
| X1 a → MC1 b | X1 / MC1 | 열림 → 닫힘 | stopOut → wlBus | 1번 준비·대기 시 WL 공급 |
| X2 a → MC2 b | X2 / MC2 | 열림 → 닫힘 | stopOut → wlBus | 2번 준비·대기 시 WL 공급 |
| MC1 a / MC2 a | MC1 / MC2 | 소자 시 열림 | stopOut → RL / GL | 모터 운전 표시 |

## 표현과 해석

- X1·X2는 각각 PB1·PB2를 우회하는 자기유지 a접점을 갖습니다. LS 감지 전에 운전 준비가 필요합니다.
- LS1·LS2는 감지 시 닫히는 **a접점**입니다. 원본의 사각형 가동부로 표현했고 감지에 따라 움직입니다.
- LS 해제는 해당 T·MC만 복귀시키며 X 자기유지는 남습니다. 재감지만으로 새 지연을 시작합니다.
- **WL = (X1 여자이고 M1 정지) 또는 (X2 여자이고 M2 정지)**입니다. 한 모터가 운전 중이어도 다른 준비 계통이 대기하면 WL은 켜집니다. 두 모터가 모두 운전 중이면 WL은 꺼집니다.
- 두 모터를 상호 금지하는 접점은 원본에 없습니다. 화면에서도 두 계통의 동시 운전을 허용합니다.
- PB0는 공통 운전선에 있어 두 계통의 자기유지를 모두 해제합니다. 감지 입력이 남아 있어도 PB1·PB2를 놓았다면 자동 재기동하지 않습니다.
- 트립 시 YL만 켜집니다. 경보 분기가 PB0보다 앞에 있으므로 트립 중 PB0를 눌러도 YL은 유지됩니다. 원본에 FLS·SS·FR·BZ가 없어 해당 조작과 부저 소리는 넣지 않았습니다.

접점·배선의 간격은 수업 화면에 맞게 조정했지만 분기·합류 및 직렬·병렬 관계는 원본을 유지합니다. 열린 접점 래스터 이미지 위에 닫힘 선을 덧씌우지 않고 접점 자체를 벡터로 개폐합니다. PB 가로 작동선, EOCR 교차 표시, T 한시 표시를 구분합니다. 9번은 SS 점선 연동·FR 마름모, 10번은 LS 사각형 가동부와 PB2도 따로 표시합니다.

설명문은 해당 입력 조건의 참고 동작으로 읽고 실제 연결을 우선했습니다. 특히 10번의 WL 소등 설명은 다른 계통이 대기하지 않는 단독 운전 사례입니다. 두 계통 중 한쪽이 대기하면 그 병렬 경로로 WL이 켜집니다. 첨부 원본의 주석은 회로 자료로만 취급했습니다.

LS는 클릭할 때마다 감지 상태를 유지하거나 해제하는 입력입니다. 접점의 물리적 감지 상태는 전원 OFF에서도 표시합니다. 실제 기계의 이동 경로, LS1·LS2 설치 위치나 물리적 상호 배타 관계는 도면에 없으므로 가정하지 않았습니다. 두 타이머는 이상적인 비유지형 온딜레이입니다. 실제 접점 바운스나 코일 소자 지연은 계산하지 않습니다.
