# 도면 005 원본 대조

근거: 전기기능사-005-A4, 2025-08-04.pdf의 실제 7페이지(11-7)와 8페이지(11-8). 2026-09-18 확인.

| 접점 | 종류·구동 기기 | 연결 경로 | 정상 상태 / 동작 조건 |
|---|---|---|---|
| EOCR 운전 | b / EOCR | 전원 → SS 및 RL·GL 분기 | 닫힘, 트립 시 열림 |
| EOCR 경보 | a / EOCR | 차단 접점 앞 전원 → YL·BZ | 열림, 트립 시 닫힘 |

| FLS | a / FLS | A 분기 → 공통 운전선 | 열림, FLS 전원·감지 시 닫힘 |
| PB0 / PB1 | b / a | 수동 분기 → 공통 운전선 | PB0 닫힘·누르면 열림 / PB1 열림·누르면 닫힘 |

| T MC2측 | 한시 a / T | FR MC2측 접점과 병렬 | 열림, 설정시간 후 닫힘 |
| MC1 / MC2 | a / 각 접촉기 | 운전 전원 → RL / GL | 열림, 각 코일 여자 시 닫힘 |

X와 T 코일은 공통 운전선에 병렬이다. FR은 T b를 거쳐 공급되고, MC1·MC2의 분기 전원은 FR 코일 전원과 별개다. 따라서 T 완료 시 FR이 꺼져도 공통선에는 전원이 남는다. FR b 복귀로 MC1이 켜지고 T a가 FR a를 우회해 MC2도 켜진다. 원본 설명과 일치한다.

FR은 b접점 경로인 M1부터 시작하는 모형이다. 기본 T 5초·FR 2초는 수업 예시값으로 M1 → M2 → M1 → 동시 운전을 보여준다. 원본은 T/FR 시간의 대소 조건을 지정하지 않는다. T가 짧으면 첫 교대 전에 동시 운전으로 전환될 수 있으므로 임의의 시간 제한을 추가하지 않았다.

PB0는 수동 분기만 차단한다. 자동 감지를 유지한 채 RESET하면 즉시 M1부터 재기동한다. 모드 전환은 기존 유지가 해제된 뒤 새 경로를 평가한다. 자동 조건이 이미 성립하거나 PB1을 계속 누른 경우 새 경로로 재기동할 수 있다. 참고 설명의 정지를 영구 기동 금지로 해석하지 않는다.

FR/T 접점 전환과 코일 응답은 이상화한다. 접촉기 시간 지연·순간 중첩·실측 전류는 계산하지 않는다. 접점 기호는 원본의 막대·작동 표시를 사용하되 개폐 간격은 구별하기 쉽게 표현한다.
