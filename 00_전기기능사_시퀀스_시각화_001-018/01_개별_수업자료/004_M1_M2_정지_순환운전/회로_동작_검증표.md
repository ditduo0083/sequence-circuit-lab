## 모델과 SVG 배선 대조

각 단계 장면과 고정 시드 혼합 입력에서 `state().loads`의 EOCR, YL, BZ, FLS, X, FR, T, MC1, MC2, RL, GL을 SVG 접점 그래프의 `calculatedLoads`와 비교했습니다. 624개 상태의 6,864개 부하 비교에서 불일치는 없었습니다.

열린 FLS·PB1·X·FR·T 접점을 건너는 통전, PE를 정상 전류 귀로로 사용하는 표시가 없는지 화면으로 확인했습니다. FR 오른쪽 출력에서 T는 직접 통전되고 MC2는 T 한시 b접점을 통과한다는 원본 연결도 대조했습니다.

## 실제 브라우저 조작

- ① 자동 M1 운전, ② M2·T 동작, ③ T 완료 후 두 모터 정지
- 수동 X 자기유지와 PB0 정지
- 실제 T·FR 시간, 일시정지·재개, 이전 단계 복원
- Space·Enter 누름/놓음, 창 포커스 이탈, 버튼 밖 포인터 놓기
- 과부하 경보 지속과 수동·자동 RESET 차이
- 시간 조건 위반 입력의 보정과 입력값 유지
- 원본 PNG 두 장 로드

캡처는 `검증/화면`에 8장, 수치 결과는 `검증/browser-results.json`에 보관했습니다.

## 채택한 가정과 실물 확인 항목

- T 2초, FR 5초는 `T < FR`을 만족하는 수업 기본값이며 도면의 고정 수치가 아닙니다.
- FR 한 위상 시간을 설정값으로 보아 전체 왕복 주기는 설정값의 두 배로 모델링했습니다.
- FR 최초 출력은 동작사항의 ①에 따라 MC1·M1 위상입니다.
- 모드 전환, 전원 재투입, RESET은 유지 상태를 지운 뒤 현재 입력을 다시 평가합니다.
- 실제 FR 초기 출력 단자, 접점 전환 공백, 릴레이 소자 지연, FLS 감지 특성, EOCR 리셋 방식은 실물과 별도 확인해야 합니다.
