# FLS 도면 004 교사용 사용안내

## 실행

`index.html`을 Chrome 또는 Edge에서 직접 엽니다. 인터넷, 계정, 별도 서버가 필요하지 않습니다. 코드 파일을 `index.html` 옆에 그대로 둡니다.

이 앱은 접점과 코일의 이상적인 논리 동작을 보여주는 수업용 모형입니다. 실측 전류, 릴레이 응답시간, FLS 전극 높이·히스테리시스, EOCR 열동 특성은 계산하지 않습니다.

## 첫 시연 순서

1. `자동 운전`에서 MCCB와 SS(A), FLS 전원 공급을 확인합니다.
2. 감지 단계에서 X·FR이 여자되고 ① M1·RL이 즉시 켜지는 것을 봅니다.
3. FR 5초 경계에서 ② M1은 꺼지고 M2·GL과 T가 함께 켜지는 것을 봅니다.
4. T 2초 경계에서 한시 b접점이 열려 ③ M2가 먼저 정지하는 것을 확인합니다. T는 다음 FR 전환까지 여자 상태입니다.
5. FR 두 번째 위상이 끝나면 T가 복귀하고 다시 M1부터 반복됩니다.
6. `수동 운전`에서 PB1을 눌렀다 놓고 X 자기유지 접점을 확인합니다.
7. `과부하 경보`에서 운전용 EOCR b접점과 경보용 a접점, YL·BZ 동시 동작을 확인합니다.
8. `자유 조작`에서 실제 시간, 일시정지, 모드 전환, RESET을 시험합니다.

## 원본에서 읽은 동작

- 자동: SS=A에서 FLS 코일이 여자됩니다. 감지 a접점이 닫히면 X와 FR이 여자되고 M1·RL부터 운전합니다.
- 수동: SS=M에서 PB1을 누르면 X와 FR이 여자되어 M1부터 운전합니다. PB1 병렬 X a접점이 자기유지합니다.
- FR 첫 위상: MC1·M1·RL ON, T·MC2·M2·GL OFF.
- FR 두 번째 위상 시작: MC1 OFF, T와 MC2 ON, M2·GL 운전.
- T 완료: T 한시 b접점이 열려 MC2만 소자됩니다. T는 FR 두 번째 위상 끝까지 여자되며 두 모터와 두 운전등은 모두 꺼집니다.
- 다음 FR 전환: T가 소자·복귀하고 MC1 경로가 닫혀 M1부터 반복합니다.
- 자동 정지: FLS 감지 해제 또는 SS=M 전환.
- 수동 정지: PB0 누름 또는 SS=A 전환.
- EOCR 트립: 운전용 b접점이 열리고 경보용 a접점이 닫혀 YL과 BZ가 동시에 계속 동작합니다.

## 시간 조건

원본 동작사항은 `T 설정시간 < FR 설정시간`을 초기 조건으로 명시합니다.

- 수업 기본값: T 2초, FR 한 위상 5초.
- 한 순환은 M1 5초 → M2 2초 → 두 모터 정지 3초이며 총 10초입니다.
- FR 시간은 각 교대 위상의 지속시간으로 해석했습니다. 전체 왕복 주기는 FR 설정의 두 배입니다.
- 입력값이 조건을 위반하면 앱이 최소 0.5초 차이를 두도록 자동 보정합니다. T를 FR 이상으로 높이면 FR도 함께 높이고, FR을 T 이하로 낮추면 T+0.5초로 유지합니다.
- FR 시간을 바꾸면 수업 편의를 위해 M1 위상, 경과 0초부터 다시 시작합니다.
- T 시간을 M2 구간 중 바꾸면 현재 경과시간과 새 설정값을 즉시 비교하여 한시 b접점 상태를 다시 계산합니다.

## 모드 전환·전원 재투입·RESET

동작사항의 “모두 정지”는 전환 순간 기존 운전 경로가 끊어진다는 뜻으로 반영했습니다. 그 뒤 새 모드의 현재 입력을 다시 평가합니다.

- A → M: 기존 자동 X 자기유지를 제거합니다. PB1이 눌려 있으면 수동 M1 운전을 새로 시작하고, 아니면 기동 대기합니다.
- M → A: 기존 수동 자기유지를 제거합니다. FLS 감지가 유지되면 M1부터 즉시 재기동하고, 감지가 해제되어 있으면 정지합니다.
- 수동 RESET: 트립 중 X 자기유지는 소실됩니다. PB1을 놓은 상태면 기동 대기하고, 계속 누른 상태면 M1부터 재기동합니다.
- 자동 RESET: 감지가 유지 중이면 위상과 시간을 초기화하고 M1부터 즉시 재기동합니다.
- MCCB OFF → ON도 같은 방식으로 현재 모드와 입력을 재평가합니다.

실제 SS 접점의 전환시간, 릴레이 소자 지연, FR의 실물 초기 출력 방식은 재현하지 않습니다.

## 화면 사용

- `전체 / 제어회로 / 운전부 / 경보부`로 확대 범위를 바꿉니다.
- `같은 기기 찾기`에서 코일과 관련 접점을 함께 강조합니다.
- 청록색 굵은 선은 부하까지 닫힌 통전 경로, 파란색 얇은 선은 전원 측 연결, 회색은 비통전 구간입니다. 색은 교류 전류의 실제 방향을 뜻하지 않습니다.
- 단계별 설명은 저장된 장면으로 이동하고, 자유 조작은 실제 초 단위로 진행됩니다. 일시정지는 FR과 T 시간을 모두 멈춥니다.
- PB1과 PB0는 순간동작 버튼입니다. 마우스, 터치, Space, Enter로 조작할 수 있습니다.
- BZ 소리는 기본 OFF이며 사용자가 켠 뒤에만 납니다.

## 접점 기호 개선 (2026-09-15)

제공 도면의 세로 접점 막대와 작동 표시를 반영했습니다. PB의 가로 작동선, SS의 선택 표시와 점선 연결, EOCR의 × 표시, FR의 ◆ 표시, T 한시 표시를 구분합니다. MC 주접점의 사선과 MCCB의 곡선도 각각 표현합니다.

T 한시 b접점은 처음에 닫혀 있고, 설정시간 후 열려 M2를 정지시킵니다. 접점 옆에는 a/b와 현재 열림·닫힘을 표시합니다. FR의 MC1 측 b접점은 소자 상태에서도 닫혀 있으며, 전원 경로가 이어져야 모터가 운전합니다.

열린 제어접점 막대는 단자 오른쪽으로 떨어지고, 닫힌 막대는 왼쪽에서 두 단자와 연결됩니다. 개폐 간격과 MCCB 개방 틈은 수업에서 구별하기 위한 표현이며 실제 기구의 이동 거리·속도를 재현하지 않습니다. **운전부 → 다음 단계**로 접점을 확대해 확인하세요.
