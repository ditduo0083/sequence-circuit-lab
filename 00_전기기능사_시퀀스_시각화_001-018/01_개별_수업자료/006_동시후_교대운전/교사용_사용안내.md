# 전기기능사 도면 006 — 교사용 사용 안내

자동 동시 운전 · 수동 동시 운전 후 교대

자동에서는 감지되는 동안 두 모터가 함께 운전합니다. 수동에서는 PB1을 누르면 두 모터가 함께 기동하고, T 완료 후 M1부터 교대합니다.

## 실행과 화면 사용

ZIP을 폴더째 압축 해제한 뒤 **index.html**을 브라우저에서 엽니다. 설치나 인터넷 연결이 필요하지 않습니다. 파일 사이의 상대 경로를 사용하므로 전체 구성을 유지하세요. 검증은 Windows Chrome에서 수행했습니다.

1. **자동 운전 / 수동 운전 / 과부하 경보**에서 수업 주제를 고릅니다. 각 주제에는 8개 장면이 있습니다.
2. **다음 단계 / 이전 / 자동 재생**은 준비된 설명 장면으로 이동합니다. 이전 단계는 해당 시점의 접점과 계시 상태를 함께 복원합니다.
3. **자유 조작으로 전환**하면 MCCB, SS, FLS, PB1, PB0, 과부하를 직접 조작하고 실제 초 단위 흐름을 관찰할 수 있습니다. **일시정지**로 시간을 멈춰 설명할 수 있습니다.
4. PB1과 PB0는 누르고 있는 동안 동작하는 버튼입니다. 마우스·터치 또는 버튼에 초점을 둔 뒤 Space/Enter를 사용하세요. 다른 창으로 이동하면 누름이 해제됩니다.
5. **전체 / 제어회로 / 운전부 / 경보부**로 관심 부분을 확대합니다. 휴대전화에서는 도면을 좌우로 밀어볼 수 있습니다.
6. **같은 기기 찾기**나 도면 접점·코일을 누르면 연관 접점과 코일을 함께 강조합니다. **원본 자료**에는 PDF의 실제 7쪽 회로도(11-7), 8쪽 동작사항(11-8)을 넣었습니다.

초록색은 닫힌 회로를 통한 통전 경로, 파란색은 전원 측 연결, 회색은 비통전을 나타냅니다. 접점에는 색뿐 아니라 열림·닫힘과 a/b 종류가 표시됩니다. 교류 회로이므로 선 색이나 모터 애니메이션이 실제 전류 방향·회전속도를 뜻하지 않습니다. 부저 소리는 기본 OFF이며 필요할 때 켭니다.

## 수업 진행 예

**자동:** MCCB ON → SS A → FLS 감지 → 두 모터 동시 운전. T 설정시간보다 오래 기다려도 교대로 바뀌지 않는 점을 확인합니다.

**수동:** SS M → PB1을 눌렀다 놓기 → 두 모터 동시 운전 → T 완료 → M1과 M2가 FR 간격으로 교대 → PB0 정지.

**과부하:** 운전 중 EOCR 과부하를 누르고 운전용 b접점과 경보용 a접점의 변화를 비교합니다. RESET은 과부하 상태를 해제합니다. 수동은 PB1을 놓았다면 대기하고, 자동은 FLS 감지가 남아 있으면 즉시 새로 운전합니다.

## 시간 설정과 기본값 예

T는 동시 운전에서 교대로 바뀌는 시간이며 기본 5초입니다. FR은 교대 간격이며 기본 2초입니다. T는 1~30초, FR은 0.5~10초를 선택할 수 있습니다. T와 FR의 대소 관계에는 제한이 없습니다.

| 수동 기동 후 | M1·RL | M2·GL | 관찰할 점 |
|---|---|---|---|
| 0초 이상, 5초 미만 | 켜짐 | 켜짐 | T 계시, FR 소자 |
| 5초 이상, 7초 미만 | 켜짐 | 꺼짐 | T 완료, FR b 닫힘 |
| 7초 이상, 9초 미만 | 꺼짐 | 켜짐 | FR a 닫힘 |
| 9초 이후 | 2초씩 교대 | 2초씩 교대 | T 완료 상태 유지 |

## 꼭 짚어볼 회로 차이

- 자동: X a접점이 운전선을 공급하고, X b접점은 T 코일을 차단합니다. T와 FR이 동작하지 않아 두 모터가 계속 운전합니다.
- 수동: PB1과 병렬인 **T 순시 a접점**이 자기유지합니다. X는 수동 자기유지용 코일이 아닙니다.
- T 완료 시 한시 b가 열려 M2의 동시 운전 경로를 끊고, 한시 a가 닫혀 FR을 기동합니다. 첫 FR 구간에는 b접점이 닫혀 M1이 운전합니다.
- 원본 RL·GL은 각각 MC1·MC2 코일과 직접 병렬입니다. 이 램프 앞에 MC 보조접점을 추가하지 않았습니다.
- 과부하 때 YL과 BZ가 동시에 계속 동작합니다. FR은 경보 점멸용이 아닙니다.

## 정지·전환·RESET의 해석

- PB0는 수동 분기에 있습니다. 자동 감지가 유지되는 동안 PB0만 누르면 자동 운전이 정지하지 않습니다.
- 자동에서 수동으로 바꾸면 PB1이 눌려 있지 않은 한 정지합니다. 수동에서 자동으로 바꾸면 FLS 감지가 남아 있을 경우 자동 기동 조건이 다시 성립합니다.
- RESET 시 PB1을 계속 누르고 있으면 수동에서도 다시 기동할 수 있습니다. 설명 장면의 수동 RESET은 PB1을 놓은 상태입니다.
- 단계별 설명은 예시 시점으로 이동합니다. 초 단위 전환 시간을 보여줄 때는 자유 조작을 사용하세요. 시간 설정 변경은 수업용 조작이며 실제 타이머의 운전 중 설정 변경 절차를 재현하지 않습니다.

## 학생 확인 질문

1. 자동에서 T가 계시하지 않는 이유는 어느 접점 때문인가요?
2. 수동에서 PB1을 놓아도 운전이 유지되는 경로를 찾아보세요.
3. T 완료 순간 M2만 먼저 멈추는 이유를 T 한시 b와 FR a로 설명해보세요.

## 자료 범위

접점 개폐·코일 여자·타이머·통전 경로를 설명하는 교육용 모델입니다. FLS의 수위 감지는 켜짐/해제로 조작하며 전극의 실제 수위 차이나 아날로그 전류·모터 관성은 모델링하지 않습니다. 접촉기·릴레이는 이상적인 개폐로, 모드 전환은 기존 유지 회로가 끊긴 뒤 새 입력을 평가하도록 처리했습니다. 원본 연결을 우선하며 실제 장비를 제어하지 않습니다.
