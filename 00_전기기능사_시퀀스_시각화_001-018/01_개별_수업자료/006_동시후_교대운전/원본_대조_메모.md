## 핵심 연결

SSA → FLS 코일, FLS a → X 코일. X a가 운전 공통선을 공급합니다. 수동은 SSM → PB0 b → (PB1 a ∥ T 순시 a)로 같은 공통선에 연결됩니다. 공통선 → X b → T, 공통선 → T 한시 a → FR, 공통선 → FR b → MC1·RL, 공통선 → (T 한시 b ∥ FR a) → MC2·GL입니다.

## 접점·부하 대응

| 접점·기기 | 정상 상태 | 원본에서의 역할 |
|---|---|---|
| EOCR b / a | 정상 닫힘 / 열림 | 트립 시 운전 차단 / YL·BZ 경보 공급 |
| SS A / M | 선택 위치만 닫힘 | A는 FLS 전원, M은 PB0·PB1 분기 |
| FLS a | 미감지 열림 | 자동 감지로 X 여자 |
| PB0 b / PB1 a | 미누름 닫힘 / 열림 | 수동 정지 / 순간 기동 |
| T 순시 a | T 소자 시 열림 | PB1과 병렬 자기유지 |
| X a / b | 소자 시 열림 / 닫힘 | 자동 운전선 공급 / T 코일 차단 |
| T 한시 a / b | 미완료 열림 / 닫힘 | 완료 후 FR 공급 / M2 동시 경로 차단 |
| FR b / a | 소자 시 닫힘 / 열림 | 교대 첫 구간 M1 / 다음 구간 M2 |
| RL / GL | 해당 코일과 병렬 | MC 보조접점 없이 MC1·MC2와 같은 전원 |

## 도면을 옮기는 기준

- 배선의 좌표와 간격은 수업 화면에 맞게 조정했습니다. 전기적 분기·합류·직렬·병렬 관계는 위의 원본 연결을 유지합니다.
- 가동 접점은 원본처럼 수직 막대를 사용합니다. 원형 단자, 열림 간격, 닫힘 연결선, PB 누름 표시, SS 선택 표시와 점선 연동, EOCR 동작 표시, FR 마름모 표시를 구분합니다.
- T의 순시 접점과 한시 접점은 이름과 시간 동작 표시로 구별합니다. 코일이 꺼져 있더라도 b접점은 정상 닫힘입니다.
- FR은 도면과 동작 순서에 맞게 b접점이 닫힌 첫 구간에서 시작하며, 설정한 구간마다 반전합니다. 실제 기기 모델별 초기 위상·동작 지연·접점 바운스는 별도입니다.
- 설명문의 포괄적 ‘정지’ 표현보다 실제 기동 입력과 접점 연결을 우선합니다. 자동 감지 유지 중 RESET, 수동→자동 전환 후 감지 입력, PB1을 누른 채 복귀하는 경우는 입력 조건에 따라 재기동합니다.
- 원본 페이지의 주석은 원자료로 보존했습니다. 이 자료 제작이나 컴퓨터 작업에 대한 지시로 취급하지 않았습니다.

## 수업에서 확인한 차이

- 자동: X a접점이 운전선을 공급하고, X b접점은 T 코일을 차단합니다. T와 FR이 동작하지 않아 두 모터가 계속 운전합니다.
- 수동: PB1과 병렬인 **T 순시 a접점**이 자기유지합니다. X는 수동 자기유지용 코일이 아닙니다.
- T 완료 시 한시 b가 열려 M2의 동시 운전 경로를 끊고, 한시 a가 닫혀 FR을 기동합니다. 첫 FR 구간에는 b접점이 닫혀 M1이 운전합니다.
- 원본 RL·GL은 각각 MC1·MC2 코일과 직접 병렬입니다. 이 램프 앞에 MC 보조접점을 추가하지 않았습니다.
- 과부하 때 YL과 BZ가 동시에 계속 동작합니다. FR은 경보 점멸용이 아닙니다.
