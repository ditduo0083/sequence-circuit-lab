시퀀스 LAB — FLS ② 지연 후 교대 운전

도면 ② · 접점 기호 개선 · 2026-09-15

실행과 첫 시연

index.html을 Chrome 또는 Edge에서 열면 실행됩니다. 인터넷이나 별도 계정이 필요하지 않습니다. 다른 PC에서는 배포용 ZIP의 압축을 모두 풀고 그 안의 index.html을 여세요.

처음에는 수동 운전 → 운전부 → 다음 단계 순서로 진행하면 좋습니다. PB1 누름과 놓음, X 자기유지, 초기 지연, M1 기동, M2로 교대, PB0 정지를 차례로 볼 수 있습니다. 각 수업 장면은 8단계입니다.

이전 도면의 시제품은 FLS_회로_동작_시각화 폴더에 유지했고, 이번 도면은 별도 폴더에 제작했습니다.

이번 회로의 핵심

구분 동작
자동 기동 A 선택 → FLS 전원 공급 → 감지 → X·T 여자
수동 기동 M 선택 → PB1 누름 → X·T 여자 → X a접점 자기유지
초기 지연 X가 여자되어도 T 한시 접점이 닫히기 전에는 두 모터 모두 정지
지연 완료 X a접점 + T 한시 a접점을 통해 FR에 전원 공급, M1부터 운전
교대 운전 FR 간격마다 M1·RL ↔ M2·GL 교대. 두 모터는 함께 운전하지 않음
정상 정지 자동: FLS 감지 해제. 수동: PB0 누름. X·T·FR 소자, 계시 초기화
과부하 운전 정지, FR 소자, YL·BZ 동시 지속 동작

이번 회로에서 자기유지는 X 접점, 초기 대기는 T, 모터 교대는 FR, 경보 공급은 EOCR 접점이 담당합니다.

단계별 설명과 자유 조작

  • 단계별 설명에서는 이전·다음 단계와 하단 단계 번호로 이동합니다. 자동 재생은 4초마다 설명 장면을 넘깁니다. T와 FR 시간은 해당 장면의 예시 시점으로 이동합니다.
  • 자유 조작에서는 현재 상태를 이어받아 스위치와 버튼을 직접 조작합니다. PB0·PB1은 놓은 상태로 전환됩니다. T와 FR은 실제 초 단위로 진행됩니다.
  • 시간 일시정지는 T의 계시, FR의 교대 시간, 모터 회전 표시와 소리를 멈춥니다. 스위치 조작은 계속할 수 있습니다.
  • 다른 탭으로 이동하거나 원본 자료를 열면 시간이 일시정지됩니다. 돌아온 뒤 시간 재개를 누르세요.
  • PB0·PB1은 누르는 동안만 동작합니다. 마우스 또는 Tab 이동 후 Space·Enter로 누르고 놓을 수 있습니다.
  • X·T·FR 등의 기기 버튼을 선택하면 코일과 해당 접점을 함께 강조합니다.
  • 전체 / 제어회로 / 운전부 / 경보부로 확대 범위를 바꿀 수 있습니다. 작은 화면에서는 회로 영역을 좌우로 밀어 봅니다.

자유 조작 예시

자동 운전

  1. 자유 조작으로 전환하고 처음으로를 누릅니다.
  2. MCCB를 ON으로 바꾸고 A 자동을 선택합니다.
  3. FLS를 감지로 바꾸면 X·T가 여자됩니다. 이때 두 모터는 정지 상태입니다.
  4. 기본 5초 후 M1이 기동합니다. 이후 기본 2초마다 M2 → M1 → M2 순서로 교대합니다.
  5. FLS를 해제하면 정지합니다. 다시 감지하면 처음부터 5초를 기다린 뒤 M1부터 시작합니다.

수동 운전

  1. 처음으로 → MCCB ON → M 수동을 선택합니다.
  2. PB1을 잠깐 눌렀다 놓습니다. X의 자기유지로 초기 계시가 계속됩니다.
  3. 설정시간 후 M1부터 교대 운전합니다.
  4. PB0를 누르면 정지합니다. PB0를 놓아도 PB1을 놓은 상태에서는 다시 기동하지 않습니다.

과부하와 리셋

운전 중 EOCR 과부하를 누르면 두 모터가 정지하고 YL과 BZ가 동시에 계속 동작합니다. FR을 통해 경보가 교대하는 회로가 아닙니다.

RESET 후에는 현재 조건을 다시 평가합니다.

  • M 위치에서 PB1을 놓은 상태: 경보 해제 후 기동 대기.
  • A 위치에서 감지 입력 유지: 경보 해제 → X·T 여자 → 초기 지연 → M1부터 교대 운전 재시작.

시간 설정과 표시

  • T 초기 지연: 기본 5초, 1~30초 범위의 수업 예시 설정.
  • FR 교대 간격: 기본 2초, 0.5·1·2·3초 중 선택. 한 모터에서 다른 모터로 바뀌는 간격이며 전체 왕복 주기는 그 두 배입니다.
  • FR 간격을 운전 중 바꾸면 M1 차례부터 새 간격을 적용합니다.
  • T 표시와 FR 표시를 따로 제공합니다. T의 지연이 끝난 뒤에는 T를 매번 다시 기다리지 않습니다.
  • 청록색 굵은 선은 통전 경로, 파란색 얇은 선은 전원 측 연결, 회색은 비통전 구간입니다. 색은 교류의 실제 전류 방향을 뜻하지 않습니다.
  • PE는 정상 운전 전류의 귀로로 표시하지 않습니다.
  • 소리는 기본 OFF입니다. 소리 ON을 선택하고 시간이 진행 중이면 BZ 동작 시 소리가 납니다.

수업 질문

  1. PB1을 놓아도 T가 계속 시간을 세는 이유는 무엇인가요?
  2. X가 여자되었는데 모터가 바로 돌지 않는 이유는 무엇인가요?
  3. FR이 M2 차례로 전환될 때 바뀌는 접점과 램프를 찾아보세요.
  4. T 설정 5초와 FR 간격 2초는 각각 어떤 시간을 뜻하나요?
  5. 과부하 시 FR이 정지했는데 YL·BZ가 켜지는 이유는 무엇인가요?

자료와 해석 범위

회로 동작 검증 기준은 한국산업인력공단 공개과제 도면을 따릅니다. 자료의 문구와 NOTE는 회로 해석을 위한 참고 내용입니다.

학습 모델은 정상 접점과 이상적인 릴레이의 논리 동작을 표현합니다. FR의 초기 출력은 제공된 설명에 따라 M1 차례로 두었고, 교대 접점은 화면에 교대 · 열림/닫힘으로 표시합니다. 실제 부품의 시간 설정, 초기 출력 방식, 단자 번호와 접점 전환 지연은 별도로 확인할 항목입니다.

SS 전환은 이전 경로가 끊어져 X가 소자된 다음 새 모드 조건을 평가하는 것으로 모델링했습니다. 실제 기기의 접점 전환시간과 릴레이 복귀시간은 재현하지 않았습니다. M→A 전환 시 감지 입력이 성립하면 새 초기 지연이 시작됩니다. PB0는 수동 분기에 있으므로 자동 운전 중 PB0만 눌러서는 정지하지 않습니다.

FLS는 감지/해제 입력으로 표현하며 구체적인 급수·배수 동작이나 전극 높이를 가정하지 않았습니다. EOCR은 과부하 발생 버튼으로 동작시키며 모터 전류나 열적 과부하 곡선은 계산하지 않습니다.

접점 기호 개선 (2026-09-15)

제공 도면의 세로 접점 막대와 작동 표시를 반영했습니다. PB의 가로 작동선, SS의 선택 표시와 점선 연결, EOCR의 × 표시, FR의 ◆ 표시, T 한시 표시를 구분합니다. MC 주접점의 사선과 MCCB의 곡선도 각각 표현합니다.

T 한시 a접점은 설정시간 후 닫힙니다. 접점 옆에는 a/b와 현재 열림·닫힘을 표시합니다. FR의 MC1 측 b접점은 소자 상태에서도 닫혀 있으며, 전원 경로가 이어져야 모터가 운전합니다.

열린 제어접점 막대는 단자 오른쪽으로 떨어지고, 닫힌 막대는 왼쪽에서 두 단자와 연결됩니다. 개폐 간격과 MCCB 개방 틈은 수업에서 구별하기 위한 표현이며 실제 기구의 이동 거리·속도를 재현하지 않습니다. 운전부 → 다음 단계로 접점을 확대해 확인하세요.
