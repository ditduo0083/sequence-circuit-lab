도면 009 교사용 사용 안내

자동 M1 단독 · 수동 순차 추가 기동

자동은 수위 감지 시 M1만 운전합니다. 수동은 PB1으로 M1을 기동하고 T 시간이 지난 뒤 M2를 추가합니다. 과부하 때는 두 모터가 정지하고 BZ부터 YL과 교대로 동작합니다.

실행과 조작

ZIP 전체를 압축 해제한 뒤 index.html을 Chrome에서 엽니다. 인터넷·설치·계정 없이 실행됩니다. 전체 파일 구성을 유지하세요. 검증 환경은 Windows Chrome입니다.

  • 단계별 설명: 24개 장면을 이전·다음·자동 재생으로 이동합니다. 장면은 예시 시점을 복원하므로 실제 초 단위 계시와 구별합니다.
  • 자유 조작: 전원·기동·정지·감지·과부하를 직접 조작합니다. 시간 일시정지·재개로 접점을 설명할 수 있습니다.
  • PB 버튼: 누르고 있는 동안 동작합니다. 마우스·터치, 또는 초점을 둔 뒤 Space/Enter를 사용할 수 있습니다. 버튼 밖에서 놓거나 창을 떠나면 누름이 해제됩니다.
  • 감지 버튼: 클릭하면 감지 상태가 유지되고 다시 클릭하면 해제됩니다.
  • 시간 설정: 입력 뒤 Tab 또는 다른 곳을 눌러 적용합니다. 운전 중 설정 변경은 수업용 기능이며 실제 기기의 변경 절차를 재현하지 않습니다.
  • 보기: 전체·제어회로·운전부·경보부로 확대합니다. 휴대전화에서는 도면을 좌우로 밀어 살펴봅니다.
  • 같은 기기 찾기: 해당 이름의 코일과 접점을 함께 강조합니다. 원본 자료에서 PDF의 실제 7쪽(11-7) 회로도와 8쪽(11-8) 동작사항을 비교합니다.

초록색은 닫힌 경로를 통한 통전, 파란색은 전원 측 연결, 회색은 비통전입니다. 색과 함께 접점의 열림·닫힘, 모터의 운전·정지 상태를 표시합니다. a/b는 정상 상태의 접점 종류이며 코일 OFF가 모든 접점 열림을 뜻하지 않습니다. 교류 회로이므로 색과 모터 회전 애니메이션은 실제 전류 방향·속도를 뜻하지 않습니다.

추천 시연 순서

  1. 자동 운전의 다음 단계로 진행해 FLS a가 MC1을 직접 공급하는 경로를 봅니다. X·T가 소자되어 M2가 켜지지 않는 것을 확인합니다.
  2. 수동 운전에서 PB1을 놓은 뒤 X a의 자기유지 경로를 찾습니다. T 완료 후 M1이 유지되고 M2가 추가되는 장면을 비교합니다.
  3. 과부하 경보에서 EOCR의 두 접점을 비교하고 BZ → YL → BZ 순서를 확인합니다.
  4. 자유 조작에서 T 1초, FR 0.5초로 바꾸어 실제 시간 흐름을 관찰한 뒤 일시정지합니다.

시간 설정

T 기본 5초는 수동 M2 추가 기동 지연입니다. 1~30초로 설정합니다. FR 기본 1초는 과부하 경보가 BZ와 YL 사이에서 바뀌는 간격입니다. 화면에서 0.5·1·2·3초를 선택합니다. 기본값에서 BZ 1초, YL 1초가 반복됩니다. 이 값들은 수업 예시이며 원본의 고정 지정값이 아닙니다.

핵심 설명

  • 수동 자기유지는 X a접점입니다. T 순시 자기유지 접점을 추가하지 않았습니다.
  • 자동 감지 경로는 SS A → FLS a → MC1입니다. 자동에서는 X·T가 여자되지 않습니다.
  • 수동 X a는 MC1 전원을 공급하며, T 한시 a는 MC2만 추가 기동합니다.
  • FR은 모터 교대용이 아니라 과부하 경보 교대용입니다. 트립 직후 BZ부터 동작합니다.
  • PB0는 수동 분기에 있어 자동 운전을 차단하지 않습니다. 자동 정지는 FLS 감지를 해제합니다.
  • 수동→자동 전환 또는 자동 RESET 시 감지가 남아 있으면 M1이 즉시 운전합니다. 수동 RESET은 PB1을 놓았다면 대기합니다. PB1을 계속 누른 채 복귀하면 새 수동 기동이 가능합니다.

원본 기준 동작표

입력·사건 기대 결과와 확인한 동작
자동 선택, 미감지 FLS만 공급, 모터 대기
자동 감지 M1·RL ON, X·T·M2 OFF
자동 60초 경과 M1만 계속 운전
수동 PB1 누름·놓음 X 자기유지, T 계시, M1·RL ON

학생 확인 질문

  1. 자동 감지 중 X와 T는 왜 꺼져 있나요?
  2. PB1과 병렬인 접점은 어느 코일에 의해 움직이나요?
  3. 과부하 직후 YL이 아닌 BZ부터 켜지는 이유는 무엇인가요?

학습 모델의 범위

FLS는 감지/해제 입력으로 단순화했습니다. 수위 높이, 급수·배수 방향, 전극 간 히스테리시스는 원본만으로 추가하지 않았습니다. 모드 전환은 기존 자기유지를 해제한 뒤 새 선택 경로를 평가합니다. FR 간격 변경은 BZ 첫 구간부터 다시 시작하는 수업용 설정입니다.

접점 개폐·코일 여자·통전 경로를 보여주는 학습 모델이며 실측 전류, 모터 관성이나 기기 시간 공차는 계산하지 않습니다. PB를 계속 누른 상태에서 정지·트립을 해제하면 현재 입력을 다시 평가하므로 해당 계통이 새로 기동할 수 있습니다. 정지·RESET 설명 장면은 기동 버튼을 놓은 조건입니다.

부저 소리는 기본 OFF입니다. 필요한 경우 소리 ON을 선택하면 자유 조작에서 BZ가 동작하는 구간에만 소리가 납니다.
