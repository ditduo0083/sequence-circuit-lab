## 연결과 판독

운전용 EOCR b 뒤에서 SS A → FLS 전원, SS A → FLS a → MC1로 이어집니다. 별도의 X a도 MC1에 병렬 공급합니다. 수동은 SS M → PB0 b → (PB1 a ∥ X 유지 a) → X·T 병렬입니다. T 한시 a는 MC2를 공급하고, MC1·MC2 보조 a는 각각 RL·GL을 켭니다. 경보용 EOCR a는 FR을 공급하며 그 뒤 FR a → YL, FR b → BZ로 갈라집니다.

| 접점 | 구동·입력 | 정상 상태 | 연결 노드 | 동작 조건·역할 |
|---|---|---|---|---|
| EOCR 운전 b / 경보 a | EOCR | 정상 닫힘 / 열림 | run / alarmBus | 트립 시 운전 차단·FR 공급 |
| SS A / M | 선택 스위치 | 선택 위치만 닫힘 | autoBus / manualBus | 자동 FLS / 수동 PB 분기 |
| FLS a | FLS 감지 | 미감지 열림 | autoBus → motor1Bus | 자동 MC1 직접 기동 |
| PB0 b / PB1 a | 누름 버튼 | 미누름 닫힘 / 열림 | manualBus → manualCommon | 수동 정지 / 순간 기동 |
| X 유지 a | X 코일 | 소자 시 열림 | PB1 병렬 | X·T 자기유지 |
| X 운전 a | X 코일 | 소자 시 열림 | run → motor1Bus | 수동 MC1 공급 |
| T 한시 a | T 코일 | 미완료 열림 | run → MC2 | 설정시간 후 M2 추가 |
| FR a / b | FR 코일 | 소자 시 열림 / 닫힘 | alarmBus → YL / BZ | BZ부터 경보 교대 |
| MC1 a / MC2 a | MC1 / MC2 | 소자 시 열림 | run → RL / GL | 운전 표시 |

## 표현과 해석

- 수동 자기유지는 **X a접점**입니다. T 순시 자기유지 접점을 추가하지 않았습니다.
- 자동 감지 경로는 SS A → FLS a → MC1입니다. 자동에서는 X·T가 여자되지 않습니다.
- 수동 X a는 MC1 전원을 공급하며, T 한시 a는 MC2만 추가 기동합니다.
- FR은 모터 교대용이 아니라 **과부하 경보 교대용**입니다. 트립 직후 BZ부터 동작합니다.
- PB0는 수동 분기에 있어 자동 운전을 차단하지 않습니다. 자동 정지는 FLS 감지를 해제합니다.
- 수동→자동 전환 또는 자동 RESET 시 감지가 남아 있으면 M1이 즉시 운전합니다. 수동 RESET은 PB1을 놓았다면 대기합니다. PB1을 계속 누른 채 복귀하면 새 수동 기동이 가능합니다.

접점·배선의 간격은 수업 화면에 맞게 조정했지만 분기·합류 및 직렬·병렬 관계는 원본을 유지합니다. 열린 접점 래스터 이미지 위에 닫힘 선을 덧씌우지 않고 접점 자체를 벡터로 개폐합니다. PB 가로 작동선, EOCR 교차 표시, T 한시 표시를 구분합니다. 9번은 SS 점선 연동·FR 마름모, 10번은 LS 사각형 가동부와 PB2도 따로 표시합니다.

설명문은 해당 입력 조건의 참고 동작으로 읽고 실제 연결을 우선했습니다. 자동 입력이 남은 상태에서 RESET하거나 자동으로 전환하면 M1 경로가 다시 성립합니다. 첨부 원본의 주석은 회로 자료로만 취급했습니다.

FLS는 감지/해제 입력으로 단순화했습니다. 수위 높이, 급수·배수 방향, 전극 간 히스테리시스는 원본만으로 추가하지 않았습니다. 모드 전환은 기존 자기유지를 해제한 뒤 새 선택 경로를 평가합니다. FR 간격 변경은 BZ 첫 구간부터 다시 시작하는 수업용 설정입니다.
