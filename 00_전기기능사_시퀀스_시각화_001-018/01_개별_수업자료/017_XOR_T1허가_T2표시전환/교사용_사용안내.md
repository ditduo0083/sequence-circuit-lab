# 전기기능사 도면 017 수업용 회로 시각화

## 실행

`index.html`을 Chrome 또는 Edge에서 엽니다. 인터넷·로그인·설치는 필요하지 않습니다. `원본 자료`에서 실제 7쪽 회로도와 8쪽 동작사항을 함께 비교할 수 있습니다.

## 추천 시연 순서

1. MCCB를 켜고 LS1만 감지합니다. X1 코일과 `X1 a → X2 b` 직렬 경로를 확인합니다.
2. PB1을 눌렀다 놓습니다. MC1·T1·M1·RL이 켜지고 T1 순시 a가 PB1을 우회하는 모습을 봅니다.
3. LS2도 감지해 두 센서 상태를 같게 만듭니다. XOR 두 분기가 모두 끊기며 M1·T1이 즉시 정지합니다.
4. LS2만 감지한 뒤 PB1을 눌러 `X1 b → X2 a` 반대 분기에서도 같은 기동을 확인합니다.
5. M1을 기동해 T1 설정시간을 채운 뒤 PB2를 누릅니다. T1 한시 a 허가와 T2 순시 a 자기유지를 확인합니다.
6. T2 완료 시 한시 b가 MC2를 끄고 한시 a가 WL을 켜는 전환을 확인합니다.
7. PB0와 EOCR 과부하/RESET을 마지막에 비교합니다.

## 화면 사용

- 단계별 설명: 저장된 대표 상태를 이전·다음으로 이동합니다. 되돌아가면 그 단계의 타이머 상태도 정확히 복원됩니다.
- 자유 조작: 실제 초 단위로 T1·T2가 진행됩니다. `시간 일시정지` 중에는 계시하지 않습니다.
- PB0·PB1·PB2: 누르는 동안만 닫히는 순간 버튼입니다. 마우스나 Space/Enter를 놓으면 복귀합니다.
- 같은 기기 찾기: 코일과 해당 접점을 함께 강조합니다.
- 전체/제어회로/운전부/경보부: 수업 초점에 맞춰 회로를 확대합니다.

## 핵심 판서

- X1 = LS1, X2 = LS2
- M1/T1 = `(PB1 ∥ T1 순시 a) · [(X1 a · X2 b) ∥ (X1 b · X2 a)]`
- M2/T2 = `(PB2 ∥ T2 순시 a) · T1 한시 a`
- T2 완료 전: MC2·M2·GL ON / WL OFF
- T2 완료 후: MC2·M2·GL OFF / WL ON

## 수업용 설정값과 범위

기본 T1 3초, T2 5초는 관찰을 쉽게 하기 위한 시연값이며 원본 도면의 고정 정격이 아닙니다. 이 앱은 도면의 이상적인 접점 논리를 보여주는 학습 모형입니다. 실제 접촉기 응답시간, 전동기 전류, 기계적 위치, 제조사별 타이머 오차는 계산하지 않습니다.
