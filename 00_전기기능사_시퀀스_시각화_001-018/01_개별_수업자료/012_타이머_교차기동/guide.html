도면 012 교사용 사용 안내

타이머 교차 기동 · LS 조건 · 순시와 한시 접점

PB1·PB2는 각각 X1·X2를 순간 기동하고 자기유지합니다. T1 완료는 X2·M2를 추가 기동하며, T2 완료는 X1을 기동합니다. LS1은 M1과 T1 차단을, LS2는 T2 계시를 제어합니다.

실행과 조작

ZIP 전체를 압축 해제한 뒤 index.html을 Chrome에서 엽니다. 인터넷·설치·계정 없이 실행됩니다. 전체 파일 구성을 유지하세요. 검증 환경은 Windows Chrome입니다.

  • 단계별 설명: 4개 수업, 총 36개 장면입니다. 이전·다음·자동 재생은 설명용 시점을 복원합니다.
  • 자유 조작: 전원·PB·LS·과부하를 직접 조작하며 실제 초 단위 계시를 관찰합니다. 일시정지·재개가 가능합니다.
  • PB 버튼: 누르고 있는 동안 작동합니다. 마우스·터치 또는 초점을 둔 뒤 Space/Enter를 사용합니다. 버튼 밖에서 놓거나 창을 떠나면 누름을 해제합니다.
  • LS 버튼: 한 번 클릭하면 감지 유지, 다시 클릭하면 해제합니다.
  • 시간 설정: 입력 후 Tab 또는 다른 곳을 눌러 적용합니다. 운전 중 설정 변경은 수업용 기능입니다.
  • 보기: 전체·제어회로·운전부·경보부를 선택해 확대합니다. 작은 화면에서는 회로 영역 안에서 좌우로 움직입니다.
  • 같은 기기 찾기: 이름을 선택하면 코일과 관련 접점을 함께 강조합니다. 다시 선택하면 강조가 해제됩니다.
  • 원본 자료: PDF 실제 7쪽(11-7) 회로도와 8쪽(11-8) 동작사항을 함께 확인합니다.

초록색은 닫힌 경로를 통한 통전, 파란색은 전원 측 연결, 회색은 비통전입니다. 색과 함께 접점 개폐 및 모터 운전·정지를 표시합니다. a/b는 정상 상태의 접점 종류이며 코일 OFF가 모든 접점 열림을 뜻하지 않습니다. 교류이므로 선 색과 모터 애니메이션은 실제 전류 방향·회전 속도를 뜻하지 않습니다.

추천 시연 순서

  1. PB1·LS1 수업에서 PB1을 순간 누르고 놓습니다. X1 자기유지, T1 계시, WL 즉시 점등을 확인합니다.
  2. T1 완료 전에 LS1을 감지시킵니다. M1이 켜지면서 MC1 b가 T1을 끊어 시간과 교차 기동이 취소됩니다.
  3. LS1을 해제하고 T1 완료까지 진행합니다. X2·M2가 추가되고, 이후 LS1 재감지로 T1이 꺼져도 X2 자기유지가 남는 것을 확인합니다.
  4. PB2·LS2 수업에서 PB2만으로 M2가 즉시 켜지고, LS2는 T2만 시작시키는 것을 비교합니다. LS2 해제는 M2를 정지시키지 않습니다.
  5. T2 완료로 X1이 기동되는 순간을 봅니다. LS1 미감지이면 T1이 0초부터 시작하고, LS1이 이미 감지되었다면 M1이 켜져 T1은 꺼져 있습니다.
  6. 순시·한시 수업에서 WL용 T 접점과 교차 기동용 T 접점을 함께 강조합니다. WL은 계시 시작부터 켜지고, 교차 기동 접점은 설정시간 후에 닫힙니다.

시간 설정

T1 기본 3초, T2 기본 5초이며 각각 1~30초로 설정합니다. T1 완료는 반대쪽 X2를, T2 완료는 반대쪽 X1을 기동합니다. 기본값은 수업 예시이며 원본은 t1·t2로 표기합니다. 한 타이머 완료로 새 타이머가 켜지면 새 타이머는 그 순간 0초부터 시작합니다.

핵심 설명

  • PB1 a ∥ X1 a ∥ T2 한시 a, PB2 a ∥ X2 a ∥ T1 한시 a 구조입니다. PB를 짧게 눌러도 X 보조 a로 자기유지합니다.
  • 1번 계통에서 LS1 a는 MC1을 직접 기동합니다. MC1 b는 T1에 직렬이므로 M1이 켜지면 T1은 차단·복귀합니다. LS1이 해제되면 X1 유지 상태에서 T1이 새로 계시합니다.
  • 2번 계통에서 MC2는 X2와 직접 병렬입니다. LS2는 T2에만 직렬이므로 M2 기동·정지 조건이 아닙니다.
  • 교차 기동 후에는 새로 기동된 X도 자기유지합니다. 원래 계통을 자동으로 끄지 않으며, 두 모터의 동시 운전도 가능합니다.
  • WL용 T1·T2 접점은 순시 a입니다. WL = T1 코일 여자 또는 T2 코일 여자이며, 설정시간 완료 전부터 점등합니다. 모터 대기 표시로 해석하지 않습니다.
  • PB0는 모든 정상 운전 분기를 끊습니다. EOCR 트립은 자기유지·타이머·모터를 복귀시키고 YL만 지속 점등합니다. PB0로 트립 경보를 끌 수는 없습니다.

학생 확인 질문

  1. M2는 LS2를 감지시키기 전에도 왜 켜질까요?
  2. LS1이 감지되면 T1이 꺼지는 접점을 찾아보세요.
  3. T1이 꺼진 뒤에도 X2가 유지되는 경로는 무엇인가요?
  4. WL은 타이머 완료 표시인가요, 코일 여자 표시인가요?

학습 모델의 범위

LS는 클릭하면 감지 상태를 유지하고 다시 클릭하면 해제하는 기계적 입력입니다. 전원 OFF에서도 물리적 접점 위치는 감지 상태에 따라 표시합니다. 실제 기계 이동 경로, LS 설치 위치나 두 LS의 물리적 상호 배타성은 도면에 없으므로 가정하지 않았습니다. 타이머는 이상적인 비유지형 온딜레이이며 전원이 끊기면 누적 시간이 복귀합니다. 접점 바운스·코일 응답 공차·모터 관성·실측 전류는 계산하지 않습니다.

PB0 또는 트립을 해제할 때 기동 PB를 계속 누르고 있으면 현재 입력을 다시 평가하여 해당 계통이 새로 기동할 수 있습니다. 정지·RESET 수업 장면은 기동 버튼을 놓은 조건입니다. 기존 누적 시간이 복원되는 것은 아닙니다.

이 도면에는 FLS·SS·FR·BZ가 없으므로 해당 조작이나 부저는 포함하지 않습니다.
