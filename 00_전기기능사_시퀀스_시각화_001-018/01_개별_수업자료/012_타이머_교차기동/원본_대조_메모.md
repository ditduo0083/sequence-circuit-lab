## 회로 연결

EOCR 운전 b → 공통 PB0 b 뒤에서 1번 (PB1 a ∥ X1 a ∥ T2 한시 a), 2번 (PB2 a ∥ X2 a ∥ T1 한시 a)로 분기합니다. 1번 합류 뒤 X1, LS1 a → MC1, MC1 b → T1이 병렬이며 2번 합류 뒤 X2, MC2, LS2 a → T2가 병렬입니다. WL은 T1 순시 a와 T2 순시 a의 병렬 경로로 공급합니다. MC 보조 a는 RL·GL을 공급합니다. EOCR 경보 a → YL은 운전 b와 PB0보다 앞에서 분기합니다.

| 접점 | 구동·입력 | 정상 상태 | 연결 위치 | 역할 |
|---|---|---|---|---|
| EOCR 운전 b / 경보 a | EOCR | 정상 닫힘 / 열림 | 운전 공통선 / YL | 트립 시 운전 차단·YL 점등 |
| PB0 b | 정지 누름 | 미누름 닫힘 | 두 계통 공통선 | 자기유지·모터·타이머 정지 |
| PB1 a / X1 a | PB1 / X1 | 미누름·소자 시 열림 | 공통선 → 1번 합류 | 1번 순간 기동·자기유지 |
| T2 한시 a | T2 | 미완료 열림 | PB1·X1 접점과 병렬 | T2 완료 후 X1 추가 기동 |
| PB2 a / X2 a | PB2 / X2 | 미누름·소자 시 열림 | 공통선 → 2번 합류 | 2번 순간 기동·자기유지 |
| T1 한시 a | T1 | 미완료 열림 | PB2·X2 접점과 병렬 | T1 완료 후 X2·M2 추가 기동 |

| LS2 a | LS2 감지 | 미감지 열림 | 2번 합류 → T2 | T2 계시, MC2와 독립 |

| MC1 a / MC2 a | MC1 / MC2 | 소자 시 열림 | 공통선 → RL / GL | 모터 운전 표시 |

## 판독과 표현

교차 기동용 접점에는 원본의 한시 표시가 있고 WL용 접점에는 없습니다. 따라서 같은 T1·T2 기기에 순시 접점과 한시 접점을 구분했습니다. T2 완료 때 T1이 기동한다는 설명은 LS1 미감지 조건이며, LS1이 감지되어 MC1이 여자되면 MC1 b 때문에 T1은 계시하지 않습니다.

접점·배선 간격은 화면에 맞게 조정하고 직렬·병렬, 분기·합류 관계를 유지했습니다. 접점은 벡터 가동부 자체를 움직여 개폐합니다. LS 사각형 가동부, PB 작동선, EOCR 교차 표시, T 한시 표시를 구분하며 b접점은 코일 소자 시 닫힙니다. 소자 상태와 열린 상태를 동일하게 취급하지 않습니다.

- PB1 a ∥ X1 a ∥ T2 한시 a, PB2 a ∥ X2 a ∥ T1 한시 a 구조입니다. PB를 짧게 눌러도 X 보조 a로 자기유지합니다.
- 1번 계통에서 LS1 a는 MC1을 직접 기동합니다. MC1 b는 T1에 직렬이므로 M1이 켜지면 T1은 차단·복귀합니다. LS1이 해제되면 X1 유지 상태에서 T1이 새로 계시합니다.
- 2번 계통에서 MC2는 X2와 직접 병렬입니다. LS2는 T2에만 직렬이므로 M2 기동·정지 조건이 아닙니다.
- 교차 기동 후에는 새로 기동된 X도 자기유지합니다. 원래 계통을 자동으로 끄지 않으며, 두 모터의 동시 운전도 가능합니다.
- WL용 T1·T2 접점은 순시 a입니다. WL = T1 코일 여자 또는 T2 코일 여자이며, 설정시간 완료 전부터 점등합니다. 모터 대기 표시로 해석하지 않습니다.
- PB0는 모든 정상 운전 분기를 끊습니다. EOCR 트립은 자기유지·타이머·모터를 복귀시키고 YL만 지속 점등합니다. PB0로 트립 경보를 끌 수는 없습니다.

LS는 클릭하면 감지 상태를 유지하고 다시 클릭하면 해제하는 기계적 입력입니다. 전원 OFF에서도 물리적 접점 위치는 감지 상태에 따라 표시합니다. 실제 기계 이동 경로, LS 설치 위치나 두 LS의 물리적 상호 배타성은 도면에 없으므로 가정하지 않았습니다. 타이머는 이상적인 비유지형 온딜레이이며 전원이 끊기면 누적 시간이 복귀합니다. 접점 바운스·코일 응답 공차·모터 관성·실측 전류는 계산하지 않습니다.

원본의 주석과 동작 설명은 회로 판독 자료로 사용했습니다. 사용자 작업 지시와 구별하며 접점 연결을 기준으로 조건별 동작을 해석했습니다.
