# 도면 014 원본 대조 메모

기준 자료: `전기기능사-014-A4, 2025-08-04.pdf` 실제 7페이지(11-7) 회로도와 8페이지(11-8) 동작사항.

## 접점·코일 연결

| 분기 | 직렬·병렬 연결 | 결과 |
|---|---|---|
| 센서 | LS1 a→X1, LS2 a→X2 | 감지별 보조 릴레이 여자 |
| M1 | PB1 ∥ T1 순시 a → X1 a → X2 a → T1 한시 b | T1·MC1 병렬 여자, M1·RL 운전 |
| M2 | PB2 ∥ T2 순시 a → (X1 a ∥ X2 a) → T2 한시 b | T2·MC2 병렬 여자, M2·GL 운전 |
| 준비등 | MC1 b → MC2 b → WL | 두 MC 소자 시 점등 |
| 보호 | EOCR b는 운전 버스, EOCR a는 YL | 트립 시 운전 정지·YL 점등 |

## 동작사항 대조

- M1은 LS1과 LS2가 모두 감지되어야 PB1로 기동합니다. 운전 중 어느 LS든 해제하면 즉시 정지합니다.
- M2는 LS1 또는 LS2 중 하나만 감지되어도 PB2로 기동합니다. 운전 중 하나를 해제해도 다른 하나가 남으면 유지되며 둘 다 해제하면 정지합니다.
- T1·T2 순시 a는 각 PB를 자기유지하고, 각 한시 b는 설정시간 완료 때 해당 T·MC를 소자해 모터를 정지시킵니다.
- PB0는 공통 정지, EOCR은 과부하 정지와 YL 경보입니다. RESET 뒤 이전 자기유지는 복구되지 않습니다.

## 학습 가정

- T1 3초·T2 5초는 시연값입니다.
- 한시 b 개방으로 코일이 소자되면 접점은 정상 닫힘으로 돌아오지만, 순시 a 자기유지가 이미 풀려 재기동하지 않는 안정 상태를 표시합니다.
- PE는 보호접지이므로 정상 통전 경로 계산에서 제외했습니다.
