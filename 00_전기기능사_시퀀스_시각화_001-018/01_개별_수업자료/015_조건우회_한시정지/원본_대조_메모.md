# 도면 015 원본 대조 메모

기준 자료: `전기기능사-015-A4, 2025-08-04.pdf` 실제 7페이지(11-7) 회로도와 8페이지(11-8) 동작사항.

## 접점·코일 연결

| 분기 | 최초 기동 경로 | 자기유지와 정지 |
|---|---|---|
| 센서 | LS1 a→X1, LS2 a→X2 | 각 감지별 보조 릴레이 여자 |
| M1 | PB1 → (X1 a ∥ X2 a) | T1 순시 a가 조건 전체를 우회, T1 한시 b로 정지 |
| M2 | PB2 → X1 a → X2 a | T2 순시 a가 조건 전체를 우회, T2 한시 b로 정지 |
| 표시 | MC1 a→RL, MC2 a→GL | MC1 b→MC2 b→WL |
| 보호 | EOCR b는 운전 버스 | EOCR a→YL |

## 동작사항 대조

- M1은 LS1 또는 LS2 중 하나가 감지되면 PB1로 기동합니다.
- M2는 LS1과 LS2가 모두 감지되어야 PB2로 기동합니다.
- 두 분기 모두 기동 뒤 T 순시 a가 PB와 센서 조건을 통째로 우회하므로 LS 해제에 따른 동작 변화가 없습니다.
- T1·T2 한시 b 완료 시 해당 모터만 정지합니다. PB0는 공통 정지, EOCR 트립은 운전 정지와 YL 점등입니다.

## 학습 가정

- T1 3초·T2 5초는 시연값입니다.
- 한시 b 개방 후 코일이 소자되어 b접점이 복귀해도 순시 a 유지 경로가 풀려 재기동하지 않는 안정 상태를 표시합니다.
- PE는 정상 통전 경로 계산에서 제외했습니다.
